## 0. 서막
작년 초부터 개발자를 준비하며 옵시디언(Obsidian)을 사용했다. 근 2년간 자료를 나름 열심히 정리했고, Google Drive와 연동해서 나름의 PKM(Personal knowledge management; 노션 등 개인 지식 관리가 가능한 서비스를 일컫는다)을 잘 구축했다고도 생각했지만, 정작 이 축적된 자료를 잘 활용한다면 좋은 개발 블로그 혹은 개인 위키를 남길 수 있지 않을까? 라는 생각이 문득 들었다. 처음에는 Velog나 Tistory로 옮기는 쉽고 간단한 방안도 고민을 했지만, **'옵시디언 자체를 블로그에 연동'**  할 수 있다면 포트폴리오 활용은 물론 배포 자동화까지 가능할 것이라는 결론에 도달했다. 그렇게 시작했다. 나의 블로그 제작 사투는...  
    
가장 큰 관점은 '무료'면서도 '커스텀'이 가능한 블로그 툴이었다. 해외에서도 Obsidian을 블로그화에 성공한 사례가 제법 많았고, 자료도 생각보다 많았기에 둘러보면서 괜찮아 보이는 것들을 선정했다.  
  
## 1. 후보 1: Digital Garden 플러그인
가장 접근성이 좋은 방식이었다. Obsidian이 지원하는 커뮤니티 플러그인을 통해 설정만 하면 바로 배포가 가능했기 때문.
  
### 특징
- **참조:** [Deep Field 공식 문서](https://dg-docs.ole.dev/)
- **장점:** 매우 쉽다. 연동 후 Formatter만 잘 설정해서 올릴 글만 지정하면 됐다.
- **단점:** 커스텀 디자인의 한계. SEO 최적화와 높은 도메인 점수를 자랑하는 Velog와 Tistory를 굳이 택하지 않은 것도 개인적으로는 '커스텀'의 한계 때문이었다. 나는 내 지식의 축적을 편하게 어디서든 볼 환경이 필요했고, 심지어 글을 수정하기 위해서는 기존 글을 삭제하고 재업로드해야 한다는 치명적 문제가 있더라. 결국 디자인과 자동화 프로세스 문제로 조금 만져보다 다른 걸로 옮기게 됐다.

## 2. 후보 2: Obsidian Blogger
GitHub 프로젝트인 [Obsidian Blogger](https://obsidian-bloger.pages.dev/)를 발견했다.

### ⚙️ 구축 프로세스
1. **Repo 설정:** GitHub 프로젝트를 다운받아 옵시디언 보관소(Vault) 폴더에 구성.
2. **배포 환경:** Cloudflare Pages를 이용해 해당 경로를 등록하고 `npm run build`를 통해 자동 배포 환경을 구축하면 되는 시스템.
3. **템플릿 자동화:** `Templater` 플러그인을 사용하여 포스트 형식을 표준화. (이건 개발 블로그가 꼭 아니더라도 정말 좋은 기능이다. 추후 시간이 되면 다뤄보려 한다)
4. **Sync 프로세스:** 옵시디언의 `Git` 플러그인을 통해 변경 사항을 **Commit-and-Sync** 하기만 하면 즉시 블로그에 반영되는 파이프라인을 완성되는 구조. 아니, 옵시디언에 Git 연동 플러그인이 있다는 건 상상도 못했다. 이게 있다면 굳이 Google Drive 같이 클라우드에 연동해서 파일을 받아볼 필요도 없지 않았을까 싶기도. (물론 당연히 Private으로 설정해야 한다)
  
![](https://velog.velcdn.com/images/paramad/post/bbd79905-f9f1-484d-a3ef-394c2025df87/image.png)
  
### 문제
- **장점:** 기본 프레임워크를 제공하고, 원하면 아예 프론트를 뜯어 고쳐서 만들 수 있는 구조였다. 고치기가 좀 쉬워보이지는 않았지만, 애초에 Sync 프로세스가 존재한다는 점에서 꽤 매력적인 선택지였다. (사실 `Templater` 플러그인과 `Git` 플러그인의 존재만으로도 얻은 게 많았다)
- **단점:** 그래서 한번 파본 결과... 내 생각보다 프론트를 고치기가 어렵다는 걸 알았다. 심지어 판지 얼마 채 지나지 않아 [Cloudflare 서버가 터지면서](https://www.vietnam.vn/ko/mot-file-loi-cua-cloudflare-khien-ca-the-gioi-khung-lai-loi-canh-bao) 접속이 불가능한 상황이 발생. 당시에는 이게 무슨 일인가 싶었는데 생각보다 굉장히 큰 사건이었고, Obsidian Blogger를 비롯한 많은 사이트에 오류가 발생한 것을 알게 됐다. 사실 11월에도 한두번 크게 터진 적이 있었기 때문에, 클라우드를 공부한 입장에서 그래도 더 안전한 플랫폼을 선택하는 게 중요하다고 판단했다.
