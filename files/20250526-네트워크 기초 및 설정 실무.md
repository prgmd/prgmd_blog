## 1. 네트워크 기초 지식
컴퓨터 간 통신을 위해 필요한 논리적 주소 체계와 관련 개념들이다.

### 1) IP 주소와 도메인
* **IP 주소**: 컴퓨터를 구별하기 위한 논리적 주소다. 현재 32비트 체계인 IPv4와 128비트 체계인 IPv6가 함께 사용된다.
* **도메인**: 숫자로 된 IP 주소를 사람이 기억하기 쉽게 문자로 변환한 주소다.
* **서브넷 마스크**: 네트워크의 규모를 나타내며, 공통 비트 수를 표기하거나(CIDR 방식) 비트 마스크 형식으로 표현한다.
* **포트 번호**: 컴퓨터 내 애플리케이션을 구별하기 위한 번호다(0~65535). HTTP는 80번, HTTPS는 443번 등 주요 서비스는 예약된 번호를 사용한다.

### 2) 통신 방식의 종류
* **Unicast**: 특정 한 곳으로만 데이터를 전송한다.
* **Multicast**: 지정된 그룹 내의 여러 대상에게 데이터를 전송한다 (예: 화상회의).
* **Broadcast**: 네트워크 내의 모든 장비에게 데이터를 전송한다.
* **Anycast**: 가장 가까운 곳의 대상 하나에게 데이터를 전송한다.

## 2. 네트워크 설정 및 관리 명령어
리눅스 시스템에서 네트워크 환경을 설정하고 제어하는 다양한 도구들이다.

### 1) nmcli (Network Manager CLI)
우분투의 기본 네트워킹 데몬인 네트워크 관리자를 제어하는 명령어다.
* **상태 확인**: `nmcli general status`로 전체 상태를 확인하거나 `nmcli device status`로 장치 상태를 볼 수 있다.
* **연결 제어**: `nmcli networking on/off`를 통해 네트워크 활성화 여부를 결정한다.

### 2) ip 명령
IP 주소, 게이트웨이, 라우팅 테이블을 관리하는 통합 명령어다.
* **주소 확인**: `ip address show`를 통해 장치별 IP 정보를 출력한다.
* **라우팅 관리**: `ip route show`로 라우팅 테이블을 확인하며, 특정 네트워크 경로를 수동으로 추가하거나 삭제할 수 있다.

### 3) ifconfig와 net-tools
전통적인 네트워크 설정 도구로, 우분투에서는 `net-tools` 패키지를 별도로 설치해야 사용 가능하다.
* **인터페이스 확인**: `ifconfig` 명령으로 IP, 넷마스크, 브로드캐스트 주소 및 MAC 주소(ether)를 확인할 수 있다.
* **루프백(lo)**: 시스템 내부 통신을 위한 가상 인터페이스로, 일반적으로 `127.0.0.1` 주소를 사용한다.

## 3. 네트워크 상태 확인 및 진단
통신 장애를 파악하거나 현재 연결 상태를 모니터링할 때 사용한다.

* **ping**: 목적지 주소와 통신이 가능한지 확인하기 위해 에코 요청 패킷을 보낸다.
* **netstat**: 모든 소켓 정보와 라우팅 정보를 출력한다. `netstat -an | grep LISTEN`을 통해 현재 열려 있는 포트를 확인할 수 있다.
* **nslookup**: 도메인 이름을 입력했을 때 DNS 서버를 통해 IP 주소를 질의한다.
* **tcpdump**: 네트워크에서 주고받는 패킷을 실시간으로 캡처하여 내용을 확인한다.

## 4. 원격 접속 및 파일 서버 서비스
서버에 원격으로 접속하거나 파일을 주고받기 위한 서비스들이다.

### 1) Telnet과 SSH
* **Telnet**: 초창기 원격 접속 프로토콜이나 데이터가 암호화되지 않아 보안에 취약하다.
* **SSH (Secure Shell)**: 모든 통신 데이터를 암호화하여 보안성이 높으며 리눅스 서버 관리의 표준이다. `systemctl status ssh`를 통해 서비스 구동 여부를 확인한다.

### 2) 파일 서버 (FTP)
* **FTP (File Transfer Protocol)**: 파일을 송수신하기 위한 프로토콜이다. 리눅스에서는 `vsftpd`와 같은 데몬을 설치하여 서버 기능을 제공하며, 설정은 `/etc/vsftpd.conf` 파일을 통해 관리한다.
