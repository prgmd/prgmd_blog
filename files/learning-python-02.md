## 1. 데이터 타입 심화 활용
단순한 저장을 넘어 데이터를 효율적으로 다루는 방법들이다.

### 1) 튜플(Tuple)의 재발견
* **Unpacking:** `*` 기호를 사용하여 데이터를 나누어 담을 수 있다. 예를 들어 여러 값을 가진 튜플에서 특정 변수에 값을 할당하고 나머지는 리스트로 묶어 대입하는 방식이다.
* **조건부 대입:** `(False일_때_값, True일_때_값)[조건]` 형식을 사용하여 간단한 if-else 처럼 활용 가능하다.
* **NamedTuple:** `collections` 모듈의 기능으로, 각 필드에 이름을 붙여 클래스처럼 접근할 수 있는 특별한 튜플이다. 데이터 전송 객체(DTO)를 만들 때 매우 유용하다.

### 2) 집합(Set)과 딕셔너리(Dict)
* **Set:** 중복을 자동으로 제거하며 순서가 없다. 내용 변경이 가능한 `set`과 변경이 불가능한 `frozenset`이 있다.
* **Dict:** 키(Key)와 값(Value)의 쌍으로 저장하며 키는 중복될 수 없다.
    * `get(키, 기본값)` 메서드를 쓰면 키가 없을 때 에러 대신 설정한 기본값을 돌려받아 안전하다.
    * `keys()`, `values()`, `items()`를 통해 키와 값을 자유롭게 뽑아낼 수 있다.

### 3) 편리한 도구들
* **enumerate:** 반복문 사용 시 데이터와 인덱스 번호를 튜플로 동시에 묶어주는 편리한 함수다.
* **Comprehension:** 한 줄의 코드로 리스트나 딕셔너리를 빠르게 생성하는 파이썬다운 문법이다.

## 2. 유용한 표준 라이브러리 모듈
기본으로 제공되지만 활용도가 매우 높은 모듈들이다.

### 1) collections 모듈
* **deque:** 양방향 큐 자료구조로, 앞뒤 어디서든 데이터를 넣고 빼는 속도가 매우 빠르다.
* **Counter:** 데이터 안의 요소 개수를 자동으로 집계해 준다.
* **defaultdict/OrderedDict:** 존재하지 않는 키에 기본값을 주거나, 입력한 데이터 순서를 기억하는 특수 딕셔너리다.

### 2) 시스템 및 경로 모듈
* **os / os.path:** 디렉토리 생성, 파일 존재 여부 확인, 파일 생성/수정 시간 확인 등 파일 시스템을 제어한다.
* **sys:** 파이썬 인터프리터 자체를 제어한다. 프로그램 종료(`exit`), 명령행 인자 확인(`argv`), 참조 횟수 확인(`getrefcount`) 등을 수행한다.
* **glob:** 경로 내의 파일 목록을 패턴(예: `*.txt`)을 이용해 순회할 때 사용한다.

## 3. 예외 처리(Exception Handling)
프로그램 실행 중에 발생하는 예상치 못한 에러를 관리하여 프로그램이 비정상적으로 죽지 않게 보호하는 기술이다.

* **try ~ except:** 에러가 날 법한 코드를 `try`에 넣고, 에러 발생 시 처리할 로직을 `except`에 작성한다.
* **else / finally:** 에러가 없을 때만 실행할 내용은 `else`, 에러 여부와 상관없이 무조건 마무리할 작업은 `finally`에 둔다.
* **raise:** 개발자가 특정 상황에서 일부러 에러를 발생시켜 흐름을 제어할 때 사용한다.
* **assert:** 특정 조건이 반드시 참이어야 함을 단언한다. 조건이 거짓이면 프로그램을 즉시 중단시킨다.

## 4. 객체의 복사 (Shallow vs Deep Copy)
변수를 단순히 대입하면 데이터 주소만 복사되어 한쪽을 고치면 원본도 바뀔 수 있다.

* **얕은 복사(copy):** 가장 바깥쪽 껍데기만 복사한다. 1차원 리스트에서는 문제가 없으나, 리스트 안의 리스트 같은 다차원 구조에서는 내부 참조값이 공유되는 문제가 있다.
* **깊은 복사(deepcopy):** 내부의 모든 데이터까지 완전히 새로 복제한다. 원본과 완전히 독립된 새로운 객체를 만들 때 필수다.

## 5. 파이썬 웹 프레임워크 맛보기
웹 서버를 만들기 위한 도구들로 각각의 특징이 있다.

* **Flask/FastAPI:** 자유도가 높아 초보자가 접근하기 좋고 가볍다.
* **Django:** 기능이 이미 다 갖춰져 있어 대규모 프로젝트에 적합하지만 자유도는 다소 낮다.
* **FastAPI 실행:** `uvicorn 메인파일명:인스턴스명 --port 8000 --reload` 명령을 사용한다. `--reload` 옵션은 개발 중 코드 수정 시 서버를 자동으로 재시작해 준다.
