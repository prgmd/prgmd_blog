## 1. MetalLB 로드 밸런서
퍼블릭 클라우드의 관리형 서비스가 없는 온프레미스 환경에서 로드 밸런싱 기능을 제공한다.

### 1) 설치 및 초기 설정
* **설치**: 매니페스트를 통해 `metallb-system` 네임스페이스에 리소스를 생성한다.
* **IP 대역 설정 (IPAddressPool)**: 로드 밸런서에 할당할 외부 IP 범위를 지정한다.
* **광고 설정 (L2Advertisement)**: 설정된 IP 풀을 네트워크에 알릴 수 있도록 L2 레이어 광고를 활성화한다.

### 2) 서비스 연동
`type: LoadBalancer`로 서비스를 생성하면 MetalLB가 가상 IP를 자동 할당하여 클러스터 외부 접근이 가능해진다.

## 2. Nginx 인그레스 실습
클러스터 내부에서 L7 로드 밸런싱을 수행하기 위해 Nginx 인그레스 컨트롤러를 활용한다.

### 1) 라우팅 실습 구조
* **호스트 기반 라우팅**: 요청 헤더의 `host` 필드에 따라 다른 백엔드 서비스로 트래픽 분산
* **경로 기반 라우팅**: URL 패스를 기준으로 트래픽 분기 처리

### 2) 로컬 접속 설정
테스트를 위해 `/etc/hosts` 파일에 워커 노드 IP와 테스트 도메인을 매핑한다.

## 3. Kustomize
쿠버네티스 커뮤니티에서 제공하는 매니페스트 템플레이팅 툴이다.

### 1) 주요 특징
* **오버레이 구조**: 베이스 파일과 환경별 오버레이 파일을 분리하여 관리
* **통합 명령어**: `kubectl kustomize` 또는 `kubectl apply -k`로 바로 사용 가능
* **리소스 결합**: `kustomization.yaml`에 리소스 목록을 정의하여 묶어서 배포

### 2) 활용 방법
* **네임스페이스/접두사**: 모든 리소스에 공통 네임스페이스나 이름 접두사를 일괄 적용
* **이미지 태그 변경**: 원본 파일 수정 없이 배포 시점에 컨테이너 이미지 태그만 변경

## 4. Helm
쿠버네티스의 패키지 매니저로, 애플리케이션을 '차트(Chart)' 단위로 관리한다.

### 1) 구성 요소
* **Chart**: 템플릿과 설정 정보가 포함된 패키지
* **Values**: 템플릿에 주입할 설정값 파일
* **Release**: 차트가 클러스터에 배포된 실행 객체

### 2) 아키텍처 및 특징
* **저장소 기반**: 헬름 저장소에서 차트를 다운로드하여 `helm install`로 간단히 배포
* **데이터 관리**: 릴리스 정보는 쿠버네티스 시크릿에 저장
* **롤백 지원**: 배포 이력 관리로 이전 상태로 쉽게 되돌릴 수 있음

### 3) 주요 명령어
* **설치**: `helm install [릴리스명] [차트경로]`
* **조회**: `helm list`로 릴리스 상태 확인
* **테스트**: `helm test`로 배포된 서비스 검증
* **삭제**: `helm uninstall`로 모든 리소스 일괄 제거
