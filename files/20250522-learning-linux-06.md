## 1. 패키지 관리와 C 언어 빌드
리눅스에서 소프트웨어를 사용하는 방법 중 하나는 소스 코드를 직접 내려받아 컴파일하여 사용하는 것이다.

### 1) 단일 및 다중 소스 컴파일
* **gcc 컴파일러**: `sudo apt install gcc`를 통해 설치하며, 단일 파일은 `gcc -o [실행파일명] [소스코드]` 명령으로 빌드한다.
* **make 도구**: 여러 개의 소스 파일로 구성된 경우, 컴파일과 링크 설정을 담은 **makefile**을 작성하여 `make` 명령 한 번으로 복잡한 빌드 과정을 자동화할 수 있다.

## 2. 리눅스의 부팅과 종료 과정
시스템 전원을 켠 순간부터 로그인 프롬프트가 뜨기까지의 복잡한 단계를 거친다.

### 1) 부팅 5단계
1. **BIOS 단계**: 하드웨어 상태를 점검하고 부팅 장치의 첫 섹터인 **MBR**에서 부트 로더 정보를 읽어온다.
2. **Boot Loader (GRUB)**: 운영체제를 선택하고 커널을 메모리에 로드한다. 우분투는 **GRUB**를 기본 부트 로더로 사용한다.
3. **Kernel 초기화**: 메모리와 장치를 검사하고 커널 프로세스(스레드)를 생성한다.
4. **systemd 서비스**: 1번 프로세스로서 각종 시스템 데몬과 서비스를 가동한다.
5. **Login Prompt**: 모든 서비스 준비가 끝나면 사용자 로그인을 기다리는 화면을 출력한다.


### 2) systemd와 서비스 제어
기본적인 서비스 관리는 `systemctl` 명령어를 사용한다.
* **주요 명령**: `start`(시작), `stop`(중단), `status`(상태 확인), `enable`(부팅 시 자동 시작).
* **런레벨(Run Level)**: 시스템의 가동 상태를 유닛 단위로 구분한다. `rescue.target`은 시스템 장애 시 관리자만 접속하여 복구하는 모드다.

### 3) 시스템 종료 (shutdown)
안전한 종료를 위해 `shutdown` 명령을 사용한다. 즉시 종료는 `now`, 예약 종료는 `+시간` 옵션을 활용하며, `-r` 옵션으로 재부팅을 수행할 수 있다.

## 3. 데몬 프로세스 (Daemon Process)
백그라운드에서 상주하며 특정 서비스를 제공하는 프로세스다.

* **동작 방식**: 항상 떠 있는 **독자형(Standalone)**과 필요할 때만 호출되는 **슈퍼 데몬(xinetd)** 방식이 있다.
* **주요 데몬**: `sshd`(원격 접속), `httpd`(웹 서버), `cron`(예약 작업), `syslogd`(로그 기록) 등이 시스템 핵심 기능을 담당한다.

## 4. 사용자 및 그룹 관리
리눅스는 다중 사용자 시스템이므로 계정 정보를 엄격히 관리한다.

### 1) 계정 관련 핵심 파일
* **/etc/passwd**: 사용자 ID, UID, 홈 디렉토리, 기본 셸 등 계정의 기본 정보가 담겨 있다.
* **/etc/shadow**: 암호화된 비밀번호와 비밀번호 만료일 등 보안 관련 정보를 저장하며 root만 열람 가능하다.
* **/etc/group**: 시스템 내 그룹 정보를 관리한다. 모든 사용자는 반드시 하나 이상의 그룹에 속해야 한다.


### 2) 사용자 관리 명령어
* **useradd**: 새로운 사용자 계정을 생성한다. 홈 디렉토리나 기본 셸을 옵션으로 지정할 수 있다.
* **passwd**: 사용자의 비밀번호를 설정하거나 변경한다.
* **암호 복구**: 비밀번호를 잊은 경우 GRUB 편집 모드에서 커널 파라미터를 수정하여 root 권한으로 접속한 뒤 재설정할 수 있다.
