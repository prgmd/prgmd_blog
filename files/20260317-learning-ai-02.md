선형 회귀와 로지스틱 회귀

## 1. 머신 러닝(Machine Learning, 기계 학습)
컴퓨터가 사람이 직접 프로그래밍하지 않아도 **데이터를 통해 스스로 학습하고 성능을 향상시키는 AI 분야**. 데이터를 기반으로 최적의 모델을 계산해 완성하고, 이를 통해 새로운 데이터를 예측하거나 분류한다.
- 예를 들어, 사과 사진을 수천 장 보여주고, 나중에 사과 사진을 보고 맞히는지 보기
- LLM에서 사용되는 신경망도 머신 러닝의 일종이다.

### 1-1. 모델

| 구분 | 전통적인 프로그래밍 | 머신 러닝 |
| :--- | :--- | :--- |
| **입력값** | 데이터 + **규칙(코드)** | 데이터 + **정답(결과)** |
| **출력값** | 결과 | **규칙(모델)** |
| **특징** | 사람이 규칙을 일일이 정해줌 | 컴퓨터가 데이터에서 규칙을 찾아냄 |

> 모델의 기본 수식: $$\hat{y} = f(x)$$
($x$: 입력값, $f$: 모델, $\hat{y}$: 예측값)

### 1-2. 3대 학습 방식
1. **지도 학습**: 정답이 있는 데이터를 주는 방식
2. **비지도 학습**: 정답 없이 데이터만 주고 공통점을 찾게 하는 방식 (군집화)
3. **강화 학습**: 행동에 대한 보상을 줘 최선의 방법을 찾게 하는 방식 (알파고, 자율 주행, AI 등)

## 2. 선형 회귀

회귀란? 쉽게 말하면 '수를 예측하는 것'. 풀어 말하면 여러 개의 독립 변수($x$)와 종속 변수($y$) 사이의 상관관계를 모델링해, 미래의 연속적인 수치값을 예측하는 기법이다.
- 왜 회귀인가? 19세기 유전학자 프랜시스 골턴(Francis Galton)이 부모의 키와 자식의 키 사이의 관계를 연구하던 중 흥미로운 법칙을 발견. 키가 아주 큰 부모의 자식은 부모보다 작고, 키가 아주 작은 부모의 자식은 부모보다 큰 경향이 있던 것. 
- 자식의 키가 무한정 커지거나 작아지는 것이 아니라, 결국 인류의 "전체 평균으로 되돌아간다(Regress to the Mean)"는 유전적 현상을 통계적으로 증명했다. 이는 과거의 유전 법칙을 넘어, 데이터들 사이의 '관계'를 함수로 나타내는 기법으로 확장

### 2-1. 추론과 오차
추세선을 만들어 낸 다음(모델 생성), 예측을 하는 구조.
- 학습: 모델을 만드는 과정
- 추론: 만든 모델을 기반으로 예측하는 것

> 선형 회귀 (1차 방정식): $$\hat{y} = ax+b$$

![](https://velog.velcdn.com/images/paramad/post/eb15594f-c81d-4f96-b46f-d92906a8da43/image.png)

> 실제 y값과 예측된 y값과의 차이를 오차라고 함. 각 점별 오차의 합이 최소가 되는 직선을 찾는 것.

#### Grid Search
a와 b의 값을 2중 for문을 돌리며 오차의 합이 최소가 되는 값을 찾는 브루트 포스 방식. 실무에서는 잘 쓰이지 않는다.

``` python
for a in a_values:
    for b in b_values:
        y_hat = a * X + b

        error = np.sum(np.abs(y - y_hat))

        if error < min_error:
            min_error = error
            best_a, best_b = a, b
```

### 2-2. MAE와 MSE
#### MAE (Mean Absolute Error)
하지만 오차의 합 값 자체는 데이터 양이 많아지면 값이 커지기 마련이고, 크게 의미가 없는 셈이다. 그래서 새롭게 고안한 방식이 **오차의 평균**을 구하는 것. `np.mean()` 함수를 이용해 구한다.

``` python
for a in a_values:
    for b in b_values:
        y_hat = a * X + b

        error = np.mean(np.abs(y - y_hat))

        if error < min_error:
            min_error = error
            best_a, best_b = a, b
```

#### MSE (Mean Sequre Error)
MAE에서 더 나아가, 아주 큰 오차가 발생했을 때 이를 강조하고 싶다면? 오차에 제곱을 해서 오차 값에 민감하게 반응하도록 만든 것. 머신 러닝 학자들은 MSE를 가장 흔하게 사용한다.

> $$MSE = \frac{1}{m} \sum_{i=1}^{m} (y^{(i)} - \hat{y}^{(i)})^2$$
- $m$: 전체 데이터의 개수
- $y^{(i)}$: $i$번째 데이터의 실제 정답
- $\hat{y}^{(i)}$: $i$번째 데이터에 대해 모델이 내놓은 예측값

``` python
for a in a_values:
    for b in b_values:
        y_hat = a * X + b

        error = np.mean(np.abs(y - y_hat) ** 2)

        if error < min_error:
            min_error = error
            best_a, best_b = a, b
```

## 3. 정규 방정식
하지만 MSE보다 더 좋은 방식이 있는데, MSE 값이 최소가 되는 a, b 값을 미분 방정식으로 쉽게 구할 수 있다. 이를 정규 방정식이라고 한다.

> $$\theta = (X^T X)^{-1} X^T y$$
- MSE에서 도출한 식이긴 한데... 과정은 패스. 어쨌든 MSE의 값이 최소가 되는 지점 (미분했을 때 0이 되는 지점)을 잘 유도해서 식을 정리하면 위 식이 나온다.

``` python
import numpy as np
import seaborn as sns

# 데이터 불러오기
tips = sns.load_dataset("tips")
X = tips["total_bill"].values.reshape(-1,1) # 세로로 긴 행렬 (n,1) 형태로 변경
Y = tips["tip"].values.reshape(-1,1) # 세로로 긴 행렬인 (n,1) 형태로 변경

# X 행렬에 앞에 [1] 추가
X_b = np.c_[np.ones((X.shape[0], 1)), X]   # [[1, x1], [1, x2], [1, x3]....]

# 정규방정식 계산: [b, a] = (X^T·X)^(-1)·X^T·Y
b, a = np.linalg.inv(X_b.T @ X_b) @ (X_b.T) @ (Y)

print("절편 b:", b) # [0.92026961]
print("기울기 a:", a) # [0.10502452]
```

![](https://velog.velcdn.com/images/paramad/post/b4fbdba1-d69a-4d5d-92f4-732c27401372/image.png)

### 3-1. 경사 하강법(GD; Gradient Descent)
하지만 이 좋아보이는 정규 방정식에는 아주 큰 단점이 있다. 수식에 역행렬이 들어가는데, 이게 계산이 되게 느리다는 것. 연산량과 메모리 사용량을 정말 많이 잡아먹고, 때로는 구할 수 없는 경우도 존재한다. 그래서 나온 방식이 **Gradient Descent(GD)**이다. 머신 러닝 전반적으로, 신경망에서도 널리 쓰이는 방법.

**전체 데이터를 확인하지 않고 최소한의 데이터만 살펴보는 방법**으로 그 값을 찾는 방법. (MSE의 미분값이 0이 되는 경우를 구하면 베스트겠지만, 굳이 그럴 필요가 없다)

1. 아무 값이나 랜덤으로 찍어본다
2. 기울기가 양수면 왼쪽으로 값을 이동, 음수면 오른쪽으로 값을 이동
3. 반복해서 절댓값이 적절히 작은 값을 도출한다

### 3-2. 아담 옵티마이저(Adam Optimizer)
다만 가끔 경사 하강법에는 다음과 같은 문제가 발생한다. 더 좋은 값을 두고, 가끔 '지역 최소점'에 갇히는 현상.

![](https://velog.velcdn.com/images/paramad/post/49115cac-fdf9-494f-b40e-98d93050f2e4/image.png)

이 경우 여러 아이디어를 적용한 버전이 아담. **이동하던 방향으로 몇 번 더 점프해보거나(관성 적용)**, 이전 점프 방향에서 좀 더 크게 뛰어본다거나 하는 식. 신경망에서는 기본 GD보다 업그레이드된 버전인 Adam를 더 많이 쓴다.

## 4. 로지스틱 회귀
> 로지스틱 회귀는 분류 기법으로, 쉽게 말하면 두 범주 중 한 범주에 속할 확률을 예측하는 기법.

좀 더 공식적인 설명은 선형 회귀의 출력값($-\infty$ ~ $+\infty$)을 **0과 1 사이의 확률값**으로 변환하여 분류 문제를 해결하는 기법. 이름은 '회귀'이지만, 실제로는 "스팸인가(1) 아니면 일반 메일인가(0)?"를 판별하는 **이진 분류(Binary Classification)**에 주로 사용.

### 4-1. 로지스틱 회귀 수식 (시그모이드)
일반적인 선형 회귀($y = ax + b$)를 그대로 분류에 쓰기에는 큰 문제가 있음. 값이 음의 무한대에서 양의 무한대까지 나올 수 있기 때문. 하지만 확률은 무조건 0에서 1 사이 값이 나와야 한다. 또한 선형 회귀는 아주 큰 값(이상치)이 하나만 들어와도 직선의 기울기가 확 변해버려 분류 기준이 망가지기 마련이다.

#### 시그모이드를 쓰는 이유
시그모이드는 연속적인 실숫값을 제한된 범위(0~1)로 압축하고, 양 끝에서 완만하게 변하므로 이런 이상치에 강하다. 또한 미분이 가능하고 매끄러운 곡선 형태라, 머신러닝 모델이 학습(경사하강법)하기에 매우 최적화된 형태를 가지고 있다.

$$f(z) = \frac{1}{1 + e^{-z}}$$

여기서 $z$ 자리에 우리가 잘 아는 선형 회귀 식($z = ax + b$)을 대입하면 로지스틱 회귀 공식이 완성된다.

$$P(y=1|x) = \frac{1}{1 + e^{-(ax + b)}}$$

### 4-2. 크로스 엔트로피
다만 이렇게 되면 0과 1 사이 값을 다루게 되므로, 오차를 제곱해서 계산하는 MSE가 한계에 도달하게 된다. 1보다 작은 소수점을 제곱하게 되면 오히려 값이 작아지기 때문. 

> 틀릴수록 기하급수적으로 큰 패널티를 부여하는 분류 전용 손실 함수

제곱 대신 로그 함수를 사용해 정답에서 멀어질수록 오차값을 무한대에 가깝게 키워버린다.
- 95% 예측 ($0.95$): 정답에 가까우므로 오차(패널티)가 거의 0에 수렴.
- 35% 예측 ($0.35$): 오차가 눈에 띄게 커지기 시작.
- 1% 예측 ($0.01$): 오차가 무한히 커진다 (강력 경고)
