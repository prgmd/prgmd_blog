## 1. 도커 컴포즈 환경 변수 설정
애플리케이션의 설정값이나 비밀번호 등을 코드와 분리하여 관리하기 위해 다양한 환경 변수 주입 방식을 사용한다.

* **직접 입력**: `docker-compose.yaml` 파일 내 `environment` 속성에 `변수명: 값` 형태로 직접 기재한다. 가장 직관적이지만 보안에 취약하다.
* **Shell 환경 변수**: 호스트 OS의 쉘에서 `export` 명령으로 변수를 선언하고, YAML 파일에서는 `${변수명}` 형태로 참조한다.
* **환경 변수 파일 (.env)**: 별도의 텍스트 파일에 변수를 모아 관리한다. 배포 환경별로 다른 파일을 사용할 수 있다.
* **Dockerfile 삽입**: 이미지를 빌드할 때 `ENV` 명령어를 사용하여 이미지 내부에 변수를 고정시킨다.

## 2. 도커 스웜 환경 구축
여러 대의 도커 호스트를 하나의 가상 리소스로 묶어 관리하는 클러스터링 환경이다.

### 1) 가상 머신 및 네트워크 설정
* **노드 구성**: 1대의 매니저 노드와 2대의 워커 노드를 준비한다.
* **호스트 이름 설정**: `hostnamectl set-hostname` 명령으로 각 노드를 구분한다.
* **IP 매핑**: `/etc/hosts` 파일에 각 노드의 IP 주소와 호스트 이름을 등록한다.

### 2) 원격 접속 및 보안 설정
* **SSH 서비스**: `openssh-server`를 설치하고 활성화한다.
* **방화벽 제어**: `ufw`가 구동 중인 경우 22번 포트를 허용한다.

### 3) 도커 설치
클러스터에 참여하는 모든 노드에 도커 엔진을 설치한다. GPG 키와 레포지토리를 추가한 후 `docker-ce`, `docker-ce-cli`, `containerd.io`를 설치한다.

## 3. 스웜 클러스터 초기화 및 노드 추가

### 1) 매니저 노드 초기화
* **초기화 명령**: `docker swarm init --advertise-addr [IP주소]`로 스웜 모드를 활성화한다.
* **통신 포트**: 2377(관리), 7946(노드 통신), 4789(오버레이 네트워크) 포트가 필요하다.
* **상태 확인**: `docker info | grep Swarm`, `docker node ls`로 확인한다.

### 2) 워커 노드 추가
* **토큰 발행**: `docker swarm join-token worker`로 참여 토큰을 확인한다.
* **노드 조인**: 워커 노드에서 조인 명령어를 입력하여 클러스터에 합류한다.

## 4. 서비스 배포 및 네트워크 구성
스웜 환경에서는 '서비스' 단위로 애플리케이션을 관리한다.

* **오버레이 네트워크**: 서로 다른 호스트의 컨테이너가 통신할 수 있는 가상 네트워크를 생성한다. (`docker network create --driver overlay [이름]`)
* **서비스 생성**: `docker service create` 명령으로 복제본 개수, 네트워크, 포트 등을 지정한다.

## 5. 도커 스택 배포
여러 개의 연관된 서비스를 하나의 그룹으로 묶어 배포한다.

### 1) 스택 설정 (YAML) 주요 속성
* **deploy**: 스웜 모드 전용 설정
    * `replicas`: 실행할 컨테이너 개수
    * `placement`: 특정 역할을 가진 노드에만 배포 제한
    * `restart_policy`: 장애 발생 시 재시작 조건 설정

### 2) 배포 및 관리
* **배포**: `docker stack deploy -c [파일명] [스택이름]`
* **확인**: `docker stack ls`, `docker stack services [스택이름]`
