def CalcSum(n):

1. `arr = list()`
2. `arr = []`

  - 왜 이런 문법이 가능한지? → 파이썬의 연산자 오버로딩과 객체 참조 매커니즘 때문
    - `*` 연산자는 내부적으로 `__mul__` 매직 메서드를 호출한다. 이 메서드는 **기존 리스트의 요소들을 지정된 횟수 만큼 얕은 복사해 새 리스트를 생성하도록 설계**되어 있음

## 2-1. 정렬 기법
### (1). 버블 정렬 (Bubble Sort)

![](https://velog.velcdn.com/images/paramad/post/d9da270b-4980-4906-997b-cadd589de954/image.png)

**인접한 두 개의 원소를 비교하며 자리를 계속 교환하는 방식**이다. 한 회전이 끝날 때마다 가장 큰 원소가 맨 뒤로 배치된다. 물 위에 거품이 올라오는 모습과 비슷하다고 해서 버블 정렬. 구현은 쉽지만 원소 이동이 많아 효율성이 낮다

* **시간 복잡도:** $O(N^2)$

#### 구현 사례 : 55, 7, 78, 12, 42
1. **1회전:** 7, 55, 12, 42, **78** (가장 큰 78이 확정)
2. **2회전:** 7, 12, 42, **55**, 78 (55 확정)
3. **3회전:** 7, 12, **42**, 55, 78 (42 확정)
4. **4회전:** 7, **12**, 42, 55, 78 (정렬 완료)

``` python
def bubblesort(a, n): # n은 a의 원소 수
    for i in range(n-1, 0, -1): # 정렬될 범위를 끝에서부터 줄여나감
        for j in range(i):
            if a[j] > a[j+1]: # 오름차순: 앞이 뒤보다 크면 교환. 만약 <로 작성시 내림차순
                a[j], a[j+1] = a[j+1], a[j]
```

#### (2). 카운팅 정렬 (Counting Sort)

각 항목이 몇 개씩 있는지 세어서 정렬된 위치를 계산하는 알고리즘이다.

* **전제 조건:** 정수 형태여야 하며, 데이터의 최댓값($k$)을 알아야 한다.
* **시간 복잡도:**  $O(n + k)$ (매우 빠름)
 
**구현 단계 (Data: [0, 4, 1, 3, 1, 2, 4, 1])**

| 단계 | 내용 | 결과 |
| :--- | :--- | :--- |
| **개수 세기** | 각 숫자의 빈도 계산 | `counts`: [1, 3, 1, 1, 2] |
| **누적합 계산** | 각 원소가 들어갈 마지막 인덱스 결정 | `counts`: [1, 4, 5, 6, 8] |
| **결과 배열 배치** | 뒤에서부터 순회하며 `temp`에 삽입 | `temp`: [0, 1, 1, 1, 2, 3, 4, 4] |

**코드 구현**

```python
def counting_sort(data, k):
    counts = [0] * (k + 1)
    temp = [0] * len(data)

    for x in data:
    	counts[x] += 1 # 빈도수
        
    for i in range(1, k + 1):
    	counts[i] += counts[i-1] # 누적합

    for i in range(len(data)-1, -1, -1): # 안정 정렬을 위해 역순 순회
        counts[data[i]] -= 1
        temp[counts[data[i]]] = data[i]
    return temp

```

### 1-2. 완전 검색 (Exhaustive Search)

모든 가능한 경우의 수를 다 체크하는 브루트 포스(Brute-force) 방식이다.

* **특징:** 무조건 답을 찾지만, 데이터가 많아지면 속도가 매우 느려진다.

#### (1) 예시 (Baby-gin)

6장의 카드 숫자가 모두 **Run**(연속된 3개) 혹은 **Triplet**(동일 숫자 3개)으로만 구성되는지 확인하는 게임이다.

* **방법:** 6개의 숫자로 만들 수 있는 모든 순열을 나열한 뒤, 앞 3자리와 뒤 3자리를 각각 검사한다.

#### (2) 순열 (Permutation)
n개 중 r개를 뽑아 나열하는 경우의 수다.
* $nPr = n \times (n-1) \times ... \times (n-r+1)$

단순하게 수열을 구현하는 방식 (1, 2, 3)
``` python
for i in range(1, 4):
	for j in range(1, 4):
    	if i != j:
        	for k in range(1, 4):
            	if i != k and j != k:
                	print(i, j, k)
```

### 1-3. 탐욕 알고리즘 (Greedy Algorithm)

그 순간에 최적이라고 생각되는 결정을 내려서 최종 해답에 도달하는 방식이다.

* **특징:** 항상 최적의 해를 보장하지는 않지만, 계산 속도가 매우 빠르다.
#### 거스름돈 줄이기
- 손님에게 거스름돈으로 주는 지폐와 동전 개수를 최소한으로 줄이기 → 그냥 단위가 큰 지폐와 동전부터 거스름돈을 주면 된다  

#### **Baby-gin 풀이:**
- 카운팅 정렬로 숫자들의 개수를 먼저 조사
1. `counts` 배열에서 Triplet(카드 3장 동일)이 있으면 제거.
2. `counts` 배열에서 Run(연속 3장)이 있으면 제거.
3. 남은 카드가 없으면 Baby-gin으로 판정.

```
num = 456789
counts = [0] * 12 # run 조사를 위해 12까지 늘림
for i in range(6):
	counts[num%10] += 1
    num //= 10

i = 0
tri, run = 0, 0

while i < 10:
	if counts[i] >= 3: # triplet 조사
    	counts[i] -= 3
        tri += 1 
        continue
    if counts[i] >= 1 and counts[i+1] >= 1 and counts[i+2] >= 1:
    	counts[i] -= 1
        counts[i+1] -= 1
        counts[i+2] -= 1
        run += 1
        continue
    i += 1

if run + tri == 2:
	print('Baby Gin')
else:
	print('Lose')
```

> 만약 7개가 넘어간다면? 123234345 같은 경우에는 3이 3개이므로 3을 먼저 제거해버림. 그러면 122445가 되므로 baby-gin 감지 실패

### 2-1. 배열 순회

배열의 모든 원소를 조사하는 방법이다.

#### (1) 행 우선 순회

가로 방향으로 먼저 읽어 나가는 방식이다.

```python
for y in range(n):
    for x in range(m):
        print(array[y][x])

```

#### (2) 열 우선 순회

세로 방향으로 먼저 읽어 나가는 방식이다.

```python
for x in range(m): # 열을 먼저 고정
    for y in range(n): # 행을 아래로 이동
        print(array[y][x])

```

#### (3) 지그재그 순회

행을 바꿀 때마다 방향을 반대로 바꾸며 읽는 방식이다.

```python
for y in range(n):
    for x in range(m):
        # y%2가 0이면 정방향(x), 1이면 역방향(m-1-x)
        print(array[y][x + (m-1-2*x) * (y%2)])
        # x + (m-1-2*x) = m-1-x
```

### 2-2. 델타 (Delta Search)

2차원 좌표에서 상하좌우 등 인접한 요소들을 탐색할 때 사용한다.

`d = [(-1, 0), (1, 0), (0, -1), (0, 1)]` (상, 하, 좌, 우)

#### (1) n*n 배열에서 각 원소 중심, 상하좌우 k칸 합계 중 최댓값

```python
max_val = 0
for y in range(n):
    for x in range(n):
        s = arr[y][x]
        for dy, dx in d:
            for c in range(1, k + 1): # k칸까지 확장
                ny, nx = y + dy * c, x + dx * c # c를 곱해 거리 조절
                if 0 <= ny < n and 0 <= nx < n:
                    s += arr[ny][nx]
        if max_val < s:
            max_val = s

```

> **Case:** 폭탄이 터졌을 때 십자 모양으로 칸까지 영향을 주는 범위를 계산하거나, 특정 지점의 가시거리를 계산할 때 유용하다.

#### (2) 전치 행렬 (Transpose)

행과 열을 서로 맞바꾸는 방식이다. (대각선을 기준으로 뒤집기)

```python
for y in range(3):
    for x in range(3):
        if y < x: # 대각선 윗부분만 선택하여 맞은편과 교환
            arr[y][x], arr[x][y] = arr[x][y], arr[y][x]
```

``` python
# n*n인 경우
new_arr = [[arr[x][y] for x in range(n)] for y in range(n)]
# [arr[x][y] for x in range(n) for y in range(n)]는 틀린 문법! 이 경우 1행으로 납작해진다
```

``` python
# 가장 쉬운 방법
new_arr = list(map(list, zip(*arr)))
```

### 2-3. 부분집합 (Subset)

집합의 원소들을 선택하여 만들 수 있는 모든 경우의 수를 구한다.

* **특징:** 원소가 개일 때 부분집합의 개수는 개다.

#### 비트마스킹 (Bitmasking)

비트 연산을 이용해 부분집합을 빠르고 효율적으로 생성한다.

* **연산자:** `&`(AND), `|`(OR), `<<`(왼쪽 시프트), `>>`(오른쪽 시프트)
* **응용:**
* `1 << n`: $2^n$ (전체 부분집합 수)
* `i & (1 << j)`: $i$라는 숫자의 $j$번째 비트가 1인지 확인 (즉, $j$번째 원소가 포함되었는지 검사)

```
arr = [3, 6, 7, 1, 5, 4]
n = len(arr)

for i in range(1<<n):
	for j in range(n):
    	if i & (1<<j):
        	print(arr[j], end=', ')
    print()
```

## 3. 검색 (Search)

저장되어 있는 자료 중에서 원하는 키를 가진 원소를 찾는 작업이다.

### 3-1. 순차 검색 (Sequential Search)

일렬로 된 자료를 순서대로 검색하는 가장 단순한 방법이다.

#### (1) 정렬되지 않은 경우

* **프로세스**: 첫 번째 원소부터 마지막까지 키 값을 비교하며 찾는다. 찾으면 인덱스를 반환하고, 끝까지 없으면 실패를 반환한다.
* **특징**: 대상이 뒤에 있을수록 오래 걸린다. 평균 비교 횟수는 $(n+1)/2$이다.
* **시간 복잡도**: $O(n)$

> **Case:** 명단에서 특정 이름을 찾을 때, 이름순으로 정렬되어 있지 않다면 맨 앞사람부터 하나씩 확인해야 한다.

#### (2) 정렬된 경우

* **프로세스**: 검색 도중 키 값보다 큰 원소가 나오면, 찾는 값이 뒤에 없다는 것이 확실하므로 검색을 즉시 종료한다.
* **시간 복잡도**: $O(n)$ (단, 검색 실패 시 비교 횟수가 평균적으로 절반으로 줄어든다.)

> **Case:** 사전에서 '가'로 시작하는 단어를 찾는데 '나'가 나오기 시작하면, 그 뒤로는 '가'가 절대 나올 수 없으니 바로 포기하는 것과 같다.

### 3-2. 이진 검색 (Binary Search)

자료의 중앙에 있는 항목과 키 값을 비교하여 다음 검색 위치를 결정하는 효율적인 방법이다. 반드시 **자료가 정렬된 상태**여야 한다.

* **프로세스**:
1. 중앙 원소 선택
2. 목표 값과 비교
3. 목표 값이 작으면 왼쪽 절반, 크면 오른쪽 절반으로 범위를 좁혀 반복
* **시간 복잡도**: $O(\log n)$

> **Case:** 업다운(Up-Down) 게임을 할 때 1~100 사이 숫자 중 50부터 부르는 것이 가장 효율적인 것과 같은 원리.

``` python
def binary_search(a, n, key):
	start = 0
    end = n-1
    while start <= end:
    	mid = (start+end)//2
        if a[mid] == key:
        	return mid
        elif a[mid] > key:
        	end = mid-1 # mid의 왼쪽 값으로 설정 (어차피 mid는 아니니까)
        else:
        	start = mid+1
    return -1
```

``` python
# 재귀 함수 이용
def binary_search(a, low, high, key):
	if low > high: # 검색 실패 케이스
    	return false 
    else:
    	mid = (high+low)//2
        if a[mid] == key:
        	return True
        elif a[mid] > key:
        	return binary_search(a, low, mid-1, key)
        else:
        	return binary_search(a, mid+1, high, key)
```

### 인덱스 (Index)

데이터베이스에서 유래한 용어로, 테이블의 동작 속도를 높여주는 자료 구조다.

* **특징**: 보통 키-필드만 가지고 있어 원본 테이블보다 용량이 훨씬 작다. (룩업 테이블)
* **효과**: 대량의 데이터를 매번 정렬하면 성능이 저하되는데, 인덱스를 활용하면 정렬 없이도 빠른 탐색이 가능하다.
* **구조**: 실제 데이터베이스에서는 이진 탐색 트리나 B-Tree 구조를 주로 사용한다.

> **Case:** 두꺼운 전공 서적 맨 뒷장에 있는 '찾아보기' 페이지. 본문을 다 뒤지지 않아도 키워드가 몇 페이지에 있는지 바로 알 수 있다.

### 3-3 선택 정렬 (Selection Sort)

주어진 자료 중 가장 작은(혹은 큰) 값을 찾아 맨 앞의 원소와 교환하는 방식이다.

* **프로세스**:
1. 전체에서 최솟값 찾기
2. 맨 앞 원소와 교환
3. 맨 앞을 제외한 나머지 구간에서 반복


* **시간 복잡도**: $O(n^2)$

> **Case:** 카드를 손에 쥐고 있을 때, 가장 작은 숫자를 찾아 맨 왼쪽으로 보내고, 그다음 작은 숫자를 찾아 그 옆으로 보내며 정리하는 방식이다.

``` python
def selection_sort(a, n):
	for i in range(n-1): # 시작 값 (돌 때마다 앞으로 한 칸씩 전진)
    	min_idx = i # 첫 원소가 최솟값이라 가정
        for j in range(i+1, n):
        	if a[min_idx] > a[j]: # 인덱스 갱신
            	min_idx = j
        a[i], a[min_idx] = a[min_idx], a[i] # 구간 최솟값을 맨 앞으로 이동
```

### 3-4 셀렉션 알고리즘 (Selection Algorithm)

저장된 자료에서 $k$번째로 크거나 작은 원소를 찾는 방법이다. 굳이 전체를 다 정렬하지 않고 $k$번만큼만 선택 정렬의 로직을 수행하면 효율적이다.

``` python
def selection(arr, k):
    # k번째까지만 반복하며 최솟값을 찾음
    for i in range(0, k): # 이 부분은 선택 정렬과 동일
        min_idx = i
        for j in range(i + 1, len(arr)):
            if arr[min_idx] > arr[j]:
                min_idx = j
        # 현재 i번째와 최솟값의 위치를 교환
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    
    # 정렬된 앞부분 중 k-1 인덱스(k번째 원소)를 반환
    return arr[k - 1]
```

> **Case:** 전교생 중 성적이 낮은 순으로 3등까지만 시상해야 할 때, 전교생을 다 정렬할 필요 없이 최하위 3명만 골라내는 것과 같다.
