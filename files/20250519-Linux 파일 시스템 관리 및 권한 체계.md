## 1. 디렉토리 및 파일 관리 명령어
리눅스 시스템에서 데이터를 구조화하고 관리하기 위한 가장 기본적인 명령어들이다.

### 1) 디렉토리 조작
* **mkdir**: 새로운 디렉토리를 생성한다. `-p` 옵션을 사용하면 하위 디렉토리까지 한 번에 생성할 수 있다.
* **rmdir**: 비어 있는 디렉토리를 삭제한다. 내용물이 있는 경우 삭제되지 않으므로 주의가 필요하다.

### 2) 파일 내용 출력 (cat, more, less, tail)
* **cat**: 파일 전체 내용을 화면에 출력한다. `-n` 옵션으로 행 번호를 붙일 수 있다.
* **more / less**: 긴 파일 내용을 화면 단위로 끊어서 보여준다. `less`는 `more`와 달리 이전 페이지로의 이동이 자유로워 더 권장된다.
* **tail**: 파일의 뒷부분을 출력한다. `-f` 옵션은 파일에 새로운 내용이 추가될 때마다 실시간으로 화면에 출력해 주어 **로그 확인**에 매우 유용하다.

### 3) 복사, 이동, 삭제 (cp, mv, rm)
* **cp**: 파일이나 디렉토리를 복사한다. 디렉토리를 복사할 때는 `-r` 옵션이 필수다.
* **mv**: 파일의 위치를 옮기거나 이름을 변경할 때 사용한다.
* **rm**: 파일이나 디렉토리를 삭제한다. `-r`은 디렉토리 삭제, `-i`는 삭제 전 확인 메시지를 띄우는 옵션이다.

## 2. 파일 찾기와 문자열 검색
수많은 파일 사이에서 필요한 정보만 빠르게 추출하는 방법이다.

* **grep**: 파일 내부의 특정 문자열(패턴)을 검색한다. `-n`을 쓰면 해당 문자열이 위치한 행 번호도 함께 알 수 있다.
* **find**: 파일명, 소유자, 권한 등을 조건으로 시스템 내 파일의 위치를 찾는다. `-exec` 기능을 활용하면 찾은 파일에 대해 즉시 특정 명령(삭제, 이동 등)을 실행할 수 있다.
* **touch**: 빈 파일을 생성하거나, 이미 존재하는 파일의 접근/수정 시간을 현재 시간으로 갱신한다.

## 3. 파일 링크 (Link)
기존 파일에 다른 이름을 붙여 사용하는 기능으로, 복잡한 경로를 짧게 줄일 때 유용하다.

### 1) 하드 링크 (Hard Link)
* 원본 파일과 동일한 **i-node** 번호를 공유한다.
* 원본 파일을 삭제해도 하드 링크가 남아 있다면 데이터는 유지된다.

### 2) 심볼릭 링크 (Symbolic Link)
* 원본 파일의 경로를 가리키는 새로운 파일을 생성한다 (윈도우의 바로가기와 유사).
* 원본 파일이 삭제되면 링크가 깨져 데이터를 읽을 수 없게 된다.
* 디렉토리나 다른 파일 시스템 간에도 설정이 가능하다.

## 4. 파일 접근 권한 관리
리눅스는 다중 사용자 시스템이므로 보안을 위해 파일마다 접근 권한을 철저히 관리한다.

### 1) 권한 구조 이해
`ls -l` 명령어로 확인하면 `rwxr-xr-x`와 같은 권한 표시를 볼 수 있다.
* **사용자 카테고리**: 소유자(User), 그룹(Group), 기타 사용자(Others) 순서로 표시된다.
* **권한 종류**: 
    - **r (읽기)**: 파일 읽기 및 복사 가능 / 디렉토리 목록 확인 가능
    - **w (쓰기)**: 파일 수정 및 삭제 가능 / 디렉토리 내 파일 생성 및 삭제 가능
    - **x (실행)**: 파일을 프로그램으로 실행 가능 / 디렉토리 내부로 진입(cd) 가능

### 2) 권한 변경 (chmod)
* **기호 모드**: `u+w`(소유자에게 쓰기 권한 추가), `go-x`(그룹과 기타 유저의 실행 권한 제거)와 같이 기호를 사용한다.
* **숫자 모드**: r=4, w=2, x=1로 계산하여 합산한다. 
    - 예: `chmod 755 [파일]` (소유자는 모든 권한, 나머지는 읽기와 실행만 가능)
    - 예: `chmod 644 [파일]` (소유자는 읽기/쓰기, 나머지는 읽기만 가능)
