## 1. 세션 고정 (Session Affinity)
특정 클라이언트의 요청을 동일한 파드로 계속 전달하도록 설정하는 기능이다.

### 1) 특징 및 설정
* **동작 원리**: 서비스에 접근한 트래픽이 한 번 파드에 할당되면, 동일 클라이언트 IP의 요청은 해당 파드로 고정된다.
* **설정 파라미터**:
  * `spec.sessionAffinity`: `ClientIP`로 설정하여 활성화
  * `spec.sessionAffinityConfig.clientIP.timeoutSeconds`: 세션 유지 시간 설정

### 2) 활용 사례
사용자 로그인 세션이 메모리에 저장되어 다른 파드로 요청이 가면 세션이 끊기는 애플리케이션에서 사용한다.

## 2. 인그레스 (Ingress)
클러스터 외부에서 내부 서비스로 접근하는 HTTP/HTTPS 경로를 관리하는 L7 로드밸런싱 리소스다.

### 1) 주요 기능
* **URL 경로 기반 라우팅**: `/api`, `/static` 등 경로에 따라 서로 다른 서비스로 트래픽 분산
* **호스트 이름 기반 라우팅**: 도메인 이름에 따라 트래픽 처리
* **SSL/TLS 터미네이션**: 보안 연결을 인그레스에서 종료하고 내부로는 일반 트래픽 전달

### 2) 인그레스 컨트롤러
인그레스 리소스는 규칙 정의일 뿐, 실제 트래픽 제어는 컨트롤러가 담당한다.
* **클라우드 통합형**: AWS ALB 인그레스 컨트롤러
* **클러스터 내부 배치형**: Nginx 인그레스 컨트롤러

## 3. Config & Storage API 개요
컨테이너에 설정이나 기밀 정보를 주입하고, 데이터를 보관할 영구 볼륨을 제공한다.

* **Secret**: 비밀번호, 토큰 등 보안 데이터 관리
* **ConfigMap**: 일반 설정값이나 스크립트 관리
* **PVC**: 파드에 영구 저장소를 할당하기 위한 요청

## 4. 환경 변수 설정
파드 템플릿의 `env` 또는 `envFrom` 필드로 컨테이너 내부에 환경 변수를 전달한다.

* **정적 설정**: 사용자가 직접 입력한 고정값
* **파드/컨테이너 정보**: 파드 이름, IP, 리소스 제한 정보
* **시크릿/컨피그맵 데이터**: 외부 리소스에서 참조

## 5. 시크릿 (Secret)
보안이 중요한 기밀 정보를 취급하기 위한 전용 리소스다.

* **저장 위치**: 마스터 노드의 `etcd`에 저장
* **데이터 전송**: 해당 시크릿을 사용하는 파드가 있는 노드에만 전송되며, 메모리 기반 `tmpfs`에 저장
* **보안 취급**: `describe`로 내용을 직접 볼 수 없으며, YAML 출력 시 `base64` 인코딩됨

## 6. 컨피그맵 (ConfigMap)
기밀 정보가 아닌 일반 설정 스크립트나 구성 파일을 관리한다.

* **데이터 마운트**: 파일 형태로 파드에 마운트하며, 실행 권한 지정 가능
* **자동 갱신**: 볼륨 마운트 시 컨피그맵 변경 내용이 약 1분 이내에 자동 업데이트
