## 1. 코드형 인프라 (IaC: Infrastructure as Code)
수동 프로세스가 아닌 코드를 통해 인프라를 구축, 관리, 프로비저닝하는 방식이다.

* **특징**: 구성 파일이 생성되므로 편집과 배포가 쉬우며, 매번 동일한 환경을 보장하는 프로비저닝이 가능하다.
* **장점**: 구성 사양을 코드화하고 문서화하여 임시 변경을 방지하고, 버전 제어를 통해 변경 이력을 관리할 수 있다. 인프라를 모듈화하여 자동화된 방식으로 결합할 수 있다.
* **주요 도구**: Docker, Kubernetes, Ansible, Terraform 등.

## 2. 도커파일 (Dockerfile)
도커 이미지를 생성하기 위한 스크립트 파일이다. 명령문을 차례대로 수행하며 사용자 정의 이미지를 빌드한다.

### 1) 주요 명령어
* **FROM**: 기반이 될 베이스 이미지를 지정한다.
* **LABEL**: 이미지에 메타데이터(버전, 작성자 등)를 추가한다.
* **RUN**: 이미지 빌드 과정에서 실행할 명령어를 기술한다. (패키지 설치 등)
* **COPY / ADD**: 호스트의 파일을 이미지 내부로 복사한다. ADD는 URL 사용이나 압축 해제 기능이 추가되어 있다.
* **WORKDIR**: 명령어가 실행될 작업 디렉토리를 설정한다.
* **EXPOSE**: 컨테이너가 개방할 포트를 지정한다.
* **CMD**: 컨테이너가 시작될 때 실행할 기본 명령을 설정한다. (하나만 유효)

### 2) PHP 애플리케이션 빌드 실습
* **Dockerfile 작성**: Ubuntu 베이스 이미지에 Apache와 PHP를 설치하고 소스 코드를 복사하는 과정을 기술한다.
* **이미지 빌드**: `docker build -t [이미지명:태그] .` 명령을 통해 현재 디렉토리의 Dockerfile을 빌드한다.
* **컨테이너 실행**: 빌드된 이미지를 바탕으로 포트 포워딩을 설정하여 컨테이너를 구동한다.

## 3. 카프카 (Kafka) 설치 및 환경 구성
파편화된 데이터 수집과 애플리케이션 간의 느슨한 결합을 지원하는 파이프라인 시스템이다.

### 1) 자바(Java) 설치
카프카는 자바 기반으로 동작하므로 JDK 설치가 선행되어야 한다.
* **설치**: `sudo apt install openjdk-17-jdk`
* **확인**: `java -version`

### 2) 카프카 설치 절차
1. **다운로드**: `wget`을 이용하여 카프카 바이너리 파일을 다운로드한다.
2. **압축 해제**: `tar` 명령어로 압축을 푼 후 `/opt/kafka` 등의 경로로 이동시킨다.
3. **환경 변수 설정**: `~/.bashrc` 파일에 `KAFKA_HOME` 경로를 추가하고 `PATH`를 업데이트하여 어디서든 명령어를 사용할 수 있게 설정한다.

### 3) 서비스 실행 (Zookeeper & Kafka)
* 카프카를 실행하기 전 코디네이터 역할을 하는 주키퍼(Zookeeper)를 먼저 실행해야 한다.
* 각각의 설정 파일(`server.properties`, `zookeeper.properties`)을 참조하여 데몬을 구동한다.
