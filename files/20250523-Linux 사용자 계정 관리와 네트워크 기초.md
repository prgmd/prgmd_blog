## 1. 사용자 계정 관리
리눅스는 다중 사용자 시스템으로, 각 사용자의 권한과 환경을 엄격히 분리하여 관리한다.

### 1) 사용자 계정 생성 (useradd & adduser)
* **useradd**: 시스템 하위 수준에서 계정을 생성한다. `-D` 옵션으로 기본 설정 값을 확인하거나 변경할 수 있다.
    - `-s`: 기본 셸 지정
    - `-m`: 홈 디렉토리 자동 생성
    - `-e`: 계정 만료일 지정
* **adduser**: 대화형 방식으로 사용자를 생성하며, 홈 디렉토리 설정과 기본 파일 배포가 더 직관적으로 수행된다.
* **/etc/skel**: 새로운 사용자 생성 시 홈 디렉토리에 공통으로 배포될 기본 설정 파일들이 들어있는 디렉토리다.

### 2) 계정 수정 및 패스워드 에이징 (usermod & chage)
* **usermod**: 이미 존재하는 계정의 UID, 그룹, 이름 등을 수정할 때 사용한다.
* **패스워드 에이징**: 비밀번호의 사용 기간을 제한하는 보안 기능이다.
    - **MIN/MAX**: 최소/최대 비밀번호 사용 가능 기간
    - **WARNING**: 만료 전 경고 알림 날수
    - **INACTIVE/EXPIRE**: 암호 만료 후 유예 기간 및 계정 자체의 만료일
    - `chage -l [계정]` 명령어로 상세한 에이징 정보를 확인할 수 있다.

### 3) 사용자 및 권한 확인
* **UID와 EUID**: `UID`는 실제 로그인한 아이디이며, `EUID`는 현재 명령을 실행 중인 유효 권한 아이디다. `SetUID`가 걸린 파일 실행 시 두 아이디가 다를 수 있다.
* **사용자 확인 명령어**:
    - `who`, `w`: 현재 시스템에 로그인한 사용자 정보와 수행 중인 작업을 출력한다.
    - `last`: 최근 로그인 및 로그아웃 기록, 터미널 정보를 보여준다.
    - `id`, `groups`: 현재 사용자의 UID, GID 및 소속된 그룹 정보를 출력한다.

## 2. 그룹 및 권한 관리
사용자들을 그룹으로 묶어 파일이나 디렉토리에 대한 접근 권한을 효율적으로 제어한다.

* **그룹 생성 및 수정**: `groupadd`로 그룹을 만들고, `groupmod`를 통해 이름이나 GID를 변경한다.
* **그룹 멤버 관리 (gpasswd)**: `-a` 옵션으로 사용자를 추가하고, `-d` 옵션으로 제거한다.
* **sudo 권한 설정**: 일반 사용자가 관리자 권한을 행사하려면 `/etc/sudoers`에 등록되어야 한다. `visudo` 명령어를 사용하여 문법 검사를 거치며 편집하는 것이 권장된다.
* **소유권 변경**: `chown`은 파일의 소유자를, `chgrp`은 소유 그룹을 변경한다.

## 3. 리눅스 네트워크 서비스 기초
네트워크는 컴퓨터 간 데이터를 주고받기 위한 통신 규약(프로토콜)을 기반으로 동작한다.

### 1) TCP/IP 5계층 구조
데이터 통신 과정을 5개의 층으로 나누어 각기 다른 역할을 수행한다.



* **Application**: HTTP, SSH, FTP 등 실제 사용자에게 제공되는 서비스 계층이다.
* **Transport**: 데이터 전달 방식을 결정한다. 신뢰성 중심의 **TCP**와 속도 중심의 **UDP**가 있다.
* **Network**: IP 주소를 기반으로 최적의 경로를 찾아 데이터를 전달한다.
* **Link / Physical**: 장치 드라이버와 실제 케이블을 통한 물리적인 연결을 담당한다.

### 2) 네트워크 주소 체계
* **MAC 주소**: 하드웨어 제조사가 부여한 물리적 주소로 16진수 12자리로 구성된다.
* **IP 주소**: 컴퓨터를 구별하는 논리적 주소로 IPv4(32비트)와 IPv6(128비트)가 있다.
* **DNS**: 숫자로 된 IP 주소를 사람이 읽기 쉬운 문자(도메인)로 변환해 주는 서비스다.
* **Port**: 한 컴퓨터 안에서 실행 중인 여러 애플리케이션을 구분하기 위한 식별 번호다.

## 4. 디스크 사용량 관리 (Quota)
특정 사용자가 디스크 공간을 독점하지 못하도록 사용량을 제한하는 기능이다.
* **설정**: `edquota` 명령어를 통해 사용자나 그룹별로 할당량을 설정한다.
* **확인**: `quota` 또는 `repquota`를 사용하여 현재 디스크 사용량과 남은 한도를 모니터링한다.
