## 1. 앤서블(Ansible) 개요
앤서블은 프로비저닝, 환경 설정, 애플리케이션 배포 등 수작업으로 진행하던 IT 업무를 코드 기반으로 작성하여 자동화하는 오픈 소스 도구이다. 현재 레드햇(RedHat)에서 관리하고 있다.

## 2. 주요 특징
### 1) 에이전트리스 (No Agent)
* 기존 도구(Puppet, Chef 등)와 달리 관리 대상 서버에 별도의 에이전트 프로그램을 설치할 필요가 없다.
* SSH 접속을 통해 파이썬(Python) 코드를 실행하는 방식이어서 관리와 운영체제별 호환성 확보가 매우 간편하다.

### 2) 멱등성 (Idempotent)
* 동일한 작업을 여러 번 수행하더라도 시스템의 최종 상태가 변하지 않고 항상 같게 유지되는 성질이다.
* 이미 설정이 완료된 항목은 다시 실행해도 중복 적용되지 않아 안전한 운영이 가능하다.

### 3) 가독성과 확장성
* YAML 문법을 사용하여 자동화 절차를 작성하므로 사람이 읽고 이해하기 쉽다.
* 단순 파일 복사부터 복잡한 클라우드 인프라 제어까지 다양한 환경을 지원하는 모듈을 제공한다.

## 3. 주요 용도
* 서버 시스템 환경 설정 자동화
* 애플리케이션의 설치 및 배포 관리
* 퍼블릭/프라이빗 클라우드 내 가상 서버 생성 및 관리

## 4. 실습 예시 및 설정

### 1) 파일 다운로드 및 디렉토리 관리
* `file` 모듈을 사용하여 디렉토리를 생성하고 권한(mode: 0755)을 부여한다.
* `get_url` 모듈을 통해 특정 URL에서 톰캣(Tomcat) 설치 파일과 체크섬 파일을 지정된 경로로 다운로드한다.

### 2) 웹 서버(Nginx) 자동화 구성
* **페이지 준비**: 관리 노드에서 배포할 메인 페이지(`index.html`)를 작성한다.
* **설정 파일 구성**: 80 포트 리스닝 및 루트 디렉토리 경로가 포함된 `nginx.conf` 파일을 작성한다.
* **플레이북(Playbook) 실행**: `webserver.yml` 파일을 작성하여 다음과 같은 순서로 작업을 자동화한다.
    - 대상 호스트(itstudy) 지정 및 root 권한(become) 설정
    - Nginx 패키지 설치
    - 설정 파일 및 index.html 복사
    - Nginx 서비스 시작 및 재시작
