## 1. 변수(Variables)의 종류와 사용법
앤서블은 인벤토리, 플레이북, 별도 파일 등 다양한 곳에서 변수를 정의하여 재사용할 수 있다.

### 1) 그룹 변수와 호스트 변수
* **그룹 변수**: 인벤토리 파일 내에서 특정 호스트 그룹 전체에 적용되는 변수이다. 그룹명 뒤에 `:vars`를 붙여 선언한다.
* **호스트 변수**: 인벤토리 내에서 특정 호스트 이름 옆에 `이름=값` 형태로 정의하며 해당 서버에서만 유효하다.

### 2) 플레이북 및 외부 파일 변수
* **vars**: 플레이북 파일 내에서 직접 변수를 선언할 때 사용한다.
* **vars_files**: 변수 정보만 담은 별도의 YAML 파일을 불러와 사용하며, 보안상 민감한 정보를 분리할 때 유용하다.

## 2. 앤서블 팩트 (Ansible Facts)
앤서블은 태스크 실행 전 관리 대상 서버의 시스템 정보를 자동으로 수집하는데 이를 '팩트'라고 한다.

* **수집 정보**: 배포판 이름(`distribution`), 버전, IP 주소, 메모리 상태, 디스크 마운트 정보 등을 포함한다.
* **사용 방법**: `ansible_facts['항목명']` 형식으로 변수처럼 호출하여 플레이북 로직에 활용할 수 있다.
* **setup 모듈**: 특정 호스트에서 수집되는 모든 팩트 정보를 확인하고 싶을 때 사용한다.

## 3. 제어문 활용 (반복문과 조건문)

### 1) 반복문 (loop)
동일한 모듈을 여러 번 실행해야 할 때 사용한다.
* `loop` 키워드 뒤에 리스트를 정의하고, 모듈 내에서는 `{{ item }}`으로 값을 받아 처리한다.
* 여러 명의 유저를 생성하거나 여러 패키지를 한 번에 설치할 때 효율적이다.

### 2) 조건문 (when)
특정 조건이 참일 때만 해당 태스크를 실행하도록 제어한다.
* **연산자**: `==`, `>`, `in`, `not in` 등을 지원하며 `and`, `or`로 복합 조건을 구성할 수 있다.
* **활용**: 특정 OS 배포판(예: RedHat)에서만 특정 패키지 매니저를 실행하도록 설정할 때 주로 사용한다.

### 3) 반복문과 조건문의 조합
`loop`와 `when`을 함께 사용하면 리스트의 각 항목을 순회하면서 특정 조건을 만족하는 항목에 대해서만 동작을 수행하도록 정교한 제어가 가능하다.
