## 1. 리눅스 서버의 방화벽 설정
리눅스 시스템은 커널 내부의 **netfilter** 모듈을 통해 패킷 필터링을 수행하며, 사용자는 이를 제어하기 위해 다양한 도구를 사용한다.

### 1) 리눅스 방화벽 도구의 종류
* **iptables**: 전통적으로 가장 많이 사용되는 도구로, netfilter의 프론트엔드 역할을 수행한다.
* **firewalld**: CentOS 7 이상 버전에서 기본으로 채택된 방화벽 관리 도구다.
* **UFW (Ubuntu FireWall)**: 우분투에서 iptables를 더 쉽게 관리할 수 있도록 제공하는 기본 방화벽 서비스다.

### 2) iptables의 구조와 체인
iptables는 정책을 테이블과 체인 단위로 관리하여 트래픽의 방향성에 따라 필터링을 수행한다.
* **주요 체인(Chain)**:
    - **INPUT**: 외부에서 서버로 유입되는 트래픽에 적용된다.
    - **OUTPUT**: 서버에서 외부로 나가는 트래픽에 적용된다.
    - **FORWARD**: 서버를 거쳐 다른 곳으로 전달되는 트래픽에 적용된다.
* **주요 테이블**: 패킷 차단 및 허용을 담당하는 **Filter 테이블**과 주소 변환을 담당하는 **NAT 테이블**이 핵심이다.

## 2. 방화벽 실무 및 명령어 활용

### 1) iptables 정책 설정 예시
* **기본 동작**: `-A` 옵션으로 체인에 규칙을 추가하며, `-p`(프로토콜), `--dport`(도도착지 포트), `-j`(처리 방식)를 지정한다.
* **웹 서버 허용/차단**:
    - `sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT` (허용)
    - `sudo iptables -A INPUT -p tcp --dport 80 -j DROP` (차단)
* **특정 IP 및 범위 제어**: `-s` 옵션으로 특정 IP를 지정하거나, `-m iprange` 모듈을 사용하여 IP 범위를 한꺼번에 차단할 수 있다.

### 2) UFW를 이용한 간편 설정
우분투 환경에서는 UFW 명령어를 통해 직관적으로 규칙을 생성한다.
* **기본 명령**: `ufw enable`(활성화), `ufw disable`(비활성화), `ufw status`(상태 확인).
* **규칙 적용**: `sudo ufw allow 80/tcp`와 같이 서비스 명칭이나 포트 번호를 사용하여 규칙을 추가하고, `delete` 명령으로 기존 규칙을 삭제한다.

## 3. 보안 관리 및 인증 도구

### 1) NMap (네트워크 스캔 도구)
서버의 활성 포트, 서비스 종류, 운영체제 정보 등을 탐색하는 강력한 도구다.
* **주요 스캔 방식**:
    - `-sS`: TCP SYN 스캔 (연결을 완전히 맺지 않는 효율적인 방식)
    - `-sU`: UDP 포트 스캔
    - `-O`: 대상 서버의 운영체제 확인
* **주의사항**: 인가되지 않은 서버를 스캔하는 행위는 공격 준비 과정으로 간주될 수 있으므로 주의가 필요하다.

### 2) PAM (삽입형 인증 모듈)
다양한 응용 프로그램의 인증 방식을 중앙에서 관리하기 위한 모듈형 프레임워크다.
* **인터페이스 종류**:
    - **auth**: 암호 확인 등 사용자 인증 수행.
    - **account**: 계정 유효성 및 접근 허용 여부 확인.
    - **password**: 암호 변경 관련 기능 제공.
    - **session**: 사용자의 로그인부터 로그아웃까지의 세션 관리.

## 4. 네트워크 설정 보안 기초
가상 머신 복제 등으로 인한 중복 문제를 해결하고 통신 환경을 최적화하는 필수 작업이다.
* **고정 IP 설정**: `/etc/netplan/*.yaml` 파일을 수정하여 인터페이스별 IP, 게이트웨이, DNS를 고정하고 `netplan apply`로 적용한다.
* **호스트 관리**: `hostnamectl set-hostname`으로 이름을 변경하고, `/etc/hosts` 파일에 도메인과 IP를 등록하여 이름 기반 통신 환경을 구축한다.
