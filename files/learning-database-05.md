## 1. 데이터베이스 및 컬렉션 상태 조회
시스템의 현재 상태를 파악하기 위한 다양한 조회 명령이다.

* **상태 정보 확인**: `db.serverStatus()`는 서버의 전반적인 정보를, `db.stats()`는 현재 데이터베이스의 통계 정보를 반환한다.
* **컬렉션 정보 조회**: `show collections`로 목록을 확인하며, `db.컬렉션이름.stats()`를 통해 특정 컬렉션의 크기나 인덱스 정보를 상세히 알 수 있다.
* **데이터 조회**: `db.컬렉션이름.find()` 명령어를 사용하여 컬렉션 내의 전체 데이터를 확인한다.

## 2. 도큐먼트 생성과 삽입 (Create)
MongoDB는 JSON 형식의 도큐먼트 단위로 데이터를 저장한다.

### 1) 삽입 함수와 특징
* **기본 특징**: 별도의 틀(Schema) 없이 삽입이 가능하며, `_id` 필드를 생략하면 자동으로 고유한 **ObjectId**가 생성된다.
* **주요 함수**:
    - **insertOne**: 데이터 하나를 삽입한다.
    - **insertMany**: 여러 데이터를 배열 형태로 묶어 한꺼번에 삽입한다.
    - **save**: 동일한 `_id`가 있으면 덮어쓰고(수정), 없으면 새로 삽입한다.

### 2) 멀티 스레드 옵션 (ordered)
여러 데이터를 삽입할 때 `ordered` 옵션을 통해 처리 방식을 정할 수 있다.
* **true (싱글 스레드)**: 순서대로 처리하며, 중간에 에러가 발생하면 이후 데이터는 삽입되지 않는다.
* **false (멀티 스레드)**: 병렬로 처리하며, 특정 데이터에서 에러가 나더라도 다른 데이터는 정상적으로 삽입된다.

### 3) 데이터 유실 방지 (writeConcern)
메모리에 먼저 작업한 후 나중에 저장 장치에 반영하는 방식의 데이터 유실을 막기 위한 옵션이다. 갑작스러운 서버 장애 시 발생할 수 있는 데이터 손실을 방지한다.

## 3. 도큐먼트 조회 (Read)
원하는 데이터를 정교하게 골라내기 위해 커서와 연산자를 활용한다.

* **find(query, projection)**:
    - **query**: 찾고 싶은 조건이다. `{"name": "bear"}`와 같이 작성한다.
    - **projection**: 보고 싶은 필드만 선택한다. `1`은 노출, `0`은 숨김을 의미한다.
* **도트(.) 연산자**: 객체 내부의 속성(`"name.firstName"`)이나 배열의 특정 순서(`"numbers.0"`)를 지정하여 조회할 때 사용한다.
* **커서(Cursor)**: 질의 결과에 하나씩 접근할 수 있게 해주는 포인터다. `toArray()`를 호출하여 전체 결과를 배열로 바꿀 수도 있다.

## 4. 도큐먼트 수정과 삭제 (Update & Delete)
데이터를 변경하거나 제거할 때 사용하는 명령어와 연산자다.

### 1) 수정 연산자
* **$set**: 특정 필드의 값만 변경한다.
* **$inc / $mul**: 값을 증가시키거나 곱한다.
* **배열 연산자**: `$push`(추가), `$pop`(제거), `$addToSet`(중복 없이 추가) 등을 사용하여 배열 데이터를 관리한다.

### 2) 수정 및 삭제 함수
* **replaceOne**: 도큐먼트 전체를 새로운 내용으로 교체한다.
* **updateMany**: 조건에 맞는 모든 데이터를 찾아 수정 연산자를 적용한다.
* **deleteMany**: 조건에 부합하는 모든 도큐먼트를 삭제한다.

## 5. Python과 MongoDB 연동 (pymongo)
파이썬 환경에서 MongoDB를 제어하기 위해서는 `pymongo` 패키지가 필요하다.

### 1) 서버 연결 및 설정
* **연결**: `pymongo.MongoClient("IP주소", 포트번호)`를 사용하여 서버에 접속한다.
* **데이터베이스 및 컬렉션**: 연결된 변수 뒤에 이름을 지정하여 선택하며, 해당 대상이 없으면 처음 데이터를 넣을 때 자동으로 생성된다.

### 2) 실무 코드 예시
파이썬의 딕셔너리 자료형을 사용하여 데이터를 삽입하고 조회한다.
* **삽입**: `insert_one(딕셔너리)` 또는 `insert_many([리스트])`를 사용한다.
* **조회**: `find()`는 여러 건을, `find_one()`은 조건에 맞는 첫 번째 데이터만 가져온다.
