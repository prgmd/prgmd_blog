# 웹 서버와 정적(Static) / 미디어(Media) 파일

## 1. 정적 파일 (Static Files)
### 1.1 정의
서버 측에서 내용이 변경되지 않고, 요청이 들어오면 고정적으로 제공되는 파일(CSS, JavaScript, 로고/아이콘 이미지, 폰트 파일 등). 개발자가 미리 준비하여 배포 시점에 확정된 자원을 의미한다. 식당에 비치된 인쇄된 메뉴판과 같다. 손님이 바뀐다고 해서 메뉴판의 내용이 변하지 않으며 항상 동일한 모습을 제공한다.

### 1.2 템플릿 사용법
- Django 내 기본 경로: 각 앱 폴더 내 `static/` 경로에 위치시킨다. (예: `articles/static/articles/style.css`)
- 템플릿 최상단에 로드 선언 후 `static` 태그를 사용하여 호출한다.

```  python
{% load static %}
<link rel="stylesheet" href="{% static 'articles/style.css' %}">
```

## 2. 미디어 파일 (Media Files)
### 2.1 정의
사용자가 웹사이트를 통해 직접 업로드하는 파일. 사이트 운영 중 사용자에 의해 동적으로 생성되고 변경되는 자원이다. 예를 들어 쇼핑몰의 기본 로고는 정적 파일이나, 사용자가 상품 후기를 작성하며 올리는 상품 사진은 미디어 파일에 해당한다.

### 2.2 저장 원리
- DB: 파일 자체가 아닌 **파일의 경로(문자열)만 저장**한다. 데이터베이스 용량 최적화 및 성능 향상을 위한 방식.
- 물리적 서버: 실제 파일은 `MEDIA_ROOT`로 지정된 서버의 특정 폴더에 저장한다.

## 3. 미디어 파일 구현 환경 설정
### 3.1. settings.py 설정
- `MEDIA_ROOT`: 사용자가 업로드한 파일이 저장될 물리적 위치를 지정한다.
  - `MEDIA_ROOT = BASE_DIR / 'media'`
- `MEDIA_URL`: 업로드된 파일에 접근할 때 사용할 웹 주소 별명이다.
  - `MEDIA_URL = 'media/'`

### 3.2. urls.py 설정
개발 환경에서 미디어 파일을 서빙하기 위해 URL 설정을 추가한다.

``` python
from django.conf import settings
from django.conf.urls.static import static

urlpatterns = [
    # ... 기존 경로 ...
] + static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

## 4. 이미지 업로드 구현 (Model/View/Template)
### 4.1. Model 구성
`ImageField`를 사용하며, 파일 첨부가 선택 사항인 경우 `blank=True`를 설정한다.

```python
class Article(models.Model):
    title = models.CharField(max_length=10)
    image = models.ImageField(upload_to='images/', blank=True)
```

### 4.2. 필수 라이브러리 및 에러 처리
`ImageField`를 사용하려면 반드시 `Pillow` 라이브러리가 설치되어야 한다. 미설치 시 migration 과정에서 `SystemCheckError`가 발생한다. (`pip install pillow`)

### 4.3. HTML 설정 (enctype)
파일 업로드 시 form 태그에 반드시 `enctype` 속성을 지정해야 한다.

```python
<form action="..." method="POST" enctype="multipart/form-data">
```

### 4.4. View 처리 (request.FILES)
폼 객체 생성 시 두 번째 인자로 파일 데이터를 전달한다. `BaseModelForm`의 생성자 인자 순서 상 `request.FILES`는 반드시 두 번째 위치에 와야 한다.

```python
form = ArticleForm(request.POST, request.FILES)
form = ArticleForm(request.POST, request.FILES, instance=article)
```

## 5. 심화
### 5.1 upload_to 속성 심화
#### 날짜 기반 경로
`strftime` 형식을 사용하여 날짜별 폴더를 자동 생성한다.
- 예: `upload_to='%Y/%m/%d/'` (2100년 1월 1일 업로드 시 2100/01/01/ 폴더 생성)

#### 함수 기반 동적 경로
유저별 폴더 등 복잡한 로직이 필요할 때 함수를 전달한다. `instance`와 `filename` 두 인자를 수신한다.

```python
def articles_image_path(instance, filename):
    return f'images/{instance.user.username}/{filename}'

image = models.ImageField(upload_to=articles_image_path)
```

### 5.2 템플릿 출력
업로드된 이미지의 웹 주소를 출력할 때는 `.url` 속성을 사용한다. 데이터가 없는 경우를 대비해 반드시 조건문을 사용한다.

```python
{% if article.image %}
    <img src="{{ article.image.url }}" alt="image">
{% endif %}
```
