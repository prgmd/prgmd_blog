## 1. Vim(VI) 편집기 고급 활용
기본적인 편집 외에도 파일 관리와 환경 설정을 통해 작업 효율을 높일 수 있다.

### 1) 파일 및 시스템 명령
* **파일 읽기 및 전환**: 
    - `:r [경로]`를 입력하면 외부 파일의 내용을 현재 커서 위치에 삽입한다.
    - `:e [경로]`를 통해 편집 중인 파일을 다른 파일로 전환할 수 있다.
* **셸 명령 실행**: 
    - `:![명령]`은 작업을 잠시 멈추고 셸 명령을 실행한 뒤 돌아온다.
    - `:sh`는 아예 셸로 빠져나갔다가 `exit`를 입력해 복귀하는 방식이다.
* **편집 편의 기능**: `.` 키를 누르면 직전에 수행한 명령을 반복하며, `~`는 커서 위치 글자의 대소문자를 서로 바꾼다.

### 2) 환경 설정
사용자 홈 디렉토리의 `.exrc` 파일에 설정을 저장하면 매번 설정할 필요가 없다.
* **주요 설정 명령**:
    - `set nu`: 행 번호 표시
    - `set list`: 눈에 보이지 않는 특수문자 표시
    - `set showmode`: 현재 편집 모드 표시
    - `set all`: 모든 설정 값 확인

## 2. 셸(Shell)의 이해와 활용
셸은 사용자와 커널 사이에서 명령을 해석하고 전달하는 중재자 역할을 수행한다.

### 1) 셸의 종류와 특징
* **Bash Shell (배시 셸)**: 리눅스의 표준 셸이자 우분투의 기본 셸이다. 본 셸(Bourne)과 호환되면서 다양한 기능을 포함하고 있다.
* **Dash Shell**: 가벼운 본 셸 기반의 셸로, 우분투에서 시스템 스크립트 실행용으로 널리 쓰인다.
* **사용자 셸 변경**: `chsh -s [셸경로]` 명령을 사용하여 로그인 셸을 원하는 것으로 변경할 수 있다.

### 2) 특수문자와 입출력 제어
* **와일드카드**: `*`(임의의 문자열), `?`(글자 한 개), `[ ]`(범위 내 한 글자) 등을 사용하여 여러 파일을 한 번에 지정한다.
* **파이프(|)**: 앞선 명령의 결과물을 뒤에 오는 명령의 입력값으로 전달한다. (예: `ls -al | more`)
* **백틱(``)**: 감싸인 문자열을 명령어로 해석하여 실행 결과를 결과물로 치환한다.


### 3) 입출력 리다이렉션 (Redirection)
장치도 파일로 관리하는 리눅스의 특성을 이용해 데이터의 방향을 바꾼다.
* **표준 스트림 번호**: 0(입력), 1(출력), 2(에러)
* **출력 리다이렉션**: `>`는 기존 내용을 덮어쓰고, `>>`는 기존 내용 끝에 추가한다.
* **에러 리다이렉션**: `2>`를 사용하여 에러 메시지만 따로 파일에 기록할 수 있다. `2>&1`을 쓰면 정상 출력과 에러를 한 파일에 섞어서 저장한다.

## 3. 리눅스 파일 시스템(File System) 구조
리눅스는 물리적인 디스크가 여러 개라도 시스템 전체에서 단 하나의 트리 구조(루트 디렉토리 `/`)만 가진다.

### 1) 파일의 종류
* **일반 파일**: 텍스트, 이미지, 실행 파일 등 데이터를 저장하는 파일이다.
* **디렉토리**: 파일과 하위 디렉토리의 정보를 담고 있는 특수 파일이다.
* **심볼릭 링크**: 윈도우의 '바로가기'와 유사하며, 원본 파일을 가리키는 별칭이다.
* **장치 파일**: 키보드, 하드디스크 등 하드웨어 장치를 파일 형태로 관리한다.

### 2) 디렉토리 주요 계층
* **/bin, /usr/bin**: 기본 실행 파일들이 위치한다.
* **/etc**: 시스템 전체의 설정 파일이 저장된다.
* **/home**: 일반 사용자의 개인 작업 공간이다.
* **/dev**: 장치 파일들이 모여 있는 곳이다.


### 3) 파일의 3요소: i-node와 데이터 블록
리눅스 파일은 이름, i-node, 데이터 블록으로 구성된다.
* **i-node (Index Node)**: 파일의 종류, 권한, 소유권, 타임스탬프 등 메타데이터를 저장하며 실제 데이터가 저장된 디스크 위치 정보를 담고 있다.
* **데이터 블록**: 실제 파일의 내용(데이터)이 물리적으로 저장되는 공간이다.
