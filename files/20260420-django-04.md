# Django Form
## 1. Django Form
### 1.1 HTML Form의 한계
지금까지 사용자로부터 데이터를 제출 받기 위해 HTML을 사용했지만, 비정상적인 요청을 필터링하는 데는 한계가 있다. 즉, 우리는 '유효성 검사'가 필요. **유효성 검사란 수집한 데이터가 정확하고 유효한지 확인하는 과정이다.** (입력 값이 비어있어요, 이메일 형식이 잘못됐어요 등)

### 1.2 Django Form
사용자 입력 데이터에 유효성 검사를 수행하기 위한 도구.

``` python 
from django import forms
```

다음과 같이 내려받아 사용하면 된다.

#### 예시
내용과 제목에 대한 사용자 입력을 받는 ArticleForm을 만들어보자.

``` python 
from django import forms

class ArticleForm(forms.Form)
	title = forms.CharField(max_length=10)
    content = forms.CharField()
```

### 1.3 Widgets
Django Form의 Widgets은 각 필드가 HTML에서 어떻게 렌더링될지 결정. 다양한 위젯 클래스를 사용해 입력 방식과 속성을 세부 조정할 수 있다. 단순 input 요소의 속성 및 출력되는 부분을 변경하는 거라 보면 된다.

### 1.4 ModelForm
사용자 입력 데이터를 DB에 저장하지 않을 때(검색, 로그인..)는 Form 사용. 저장해야 한다면 ModelForm 사용. 모델 필드를 기반으로 입력 폼을 자동 생성해주고, 수집과 저장 과정을 동시에 처리해준다.

``` python
class ArticleForm(forms.ModelForm):
	class Meta:
    	model = Article
        fields = '__all__'
```

#### Meta Class
ModelForm의 정보를 작성하는 곳. 내부에서 어떤 모델과 연결할지, 어떤 필드를 사용할지 정의하는 설정 공간이다. Form의 동작 방식을 제어하는 핵심 역할. fields 대신 exclude를 사용해서 '모델에 포함하지 않도록 필드를 지정'할 수 도 있다.

#### `is_valid()`
여러 유효성 검사를 실행한 뒤 데이터가 유효한지 여부를 Bool 형태로 반환. 

#### `save()`
폼 데이터가 유효하면 대체로 `save()` 메서드를 호출해 모델 인스턴스를 생성하고 DB에 저장. 일반적으로는 새 객체를 생성하고, `instance` 인자를 넣으면 '기존 객체 수정' 모드로 바뀐다.

``` python
# CREATE 
form = ArticleForm(request.POST)
form.save()

# UPDATE
form = ArticleForm(request.POST, instance=article)
form.save()
```

## 2. 응용
### 2.1 new & create 함수 결합
이전 게시물에서 말한 new와 create 함수를 결합하는 방법. 이렇게 바꾼 다음 new 관련 구문을 전부 create로 변경해준다.

``` python
# articles/views.py

def create(request):
    if request.method == 'POST':
        form = ArticleForm(request.POST)
        if form.is_valid():
            article = form.save()
            return redirect('articles:detail', article.pk)
    else:
        form = ArticleForm()
    context = {
        'form': form,
    }
    return render(request, 'articles/new.html', context)
```

(GET) articles/create/ : 게시글 생성 페이지
(POST) articles/create/ : 게시글 생성

### 2.2 edit & update 함수 결합

``` python
# articles/views.py

def update(request, pk):
    article = Article.objects.get(pk=pk)
    if request.method == 'POST':
        form = ArticleForm(request.POST, instance=article)
        if form.is_valid():
            form.save()
            return redirect('articles:detail', article.pk)
    else:
        form = ArticleForm(instance=article)
    context = {
        'article': article,
        'form': form,
    }
    return render(request, 'articles/update.html', context)
```
