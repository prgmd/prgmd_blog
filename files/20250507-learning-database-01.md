## 1. 데이터베이스와 DBMS의 이해

### 1.1 데이터베이스(Database)란?

데이터베이스는 여러 사람이 공유하여 사용할 목적으로 통합 관리되는 데이터의 집합이다. 단순히 저장만 하는 것이 아니라, 데이터에 결함이 없는 상태인 **무결성**을 유지하며 실시간으로 접근할 수 있어야 한다.

### 1.2 DBMS (Database Management System)

데이터를 편리하게 관리하고 효율적으로 저장 및 검색할 수 있게 도와주는 소프트웨어다.

* **역할**: 데이터 구조를 정의하고, 조작하며, 보안이나 회복 같은 제어 기능을 담당한다.
* **종료**: Oracle, MySQL 같은 상용 제품과 MariaDB, PostgreSQL 같은 오픈 소스 제품이 있다.

### 1.3 관계형 데이터베이스(RDBMS) 구성

데이터를 표(Table) 형태로 관리하는 시스템이다.

* **릴레이션(Relation)**: 테이블 그 자체를 말한다.
* **속성(Attribute)**: 테이블의 열(Column)이다. 데이터의 특징을 정의한다.
* **튜플(Tuple)**: 테이블의 행(Row)이다. 실제 데이터 한 건을 의미한다.

## 2. SQL 기초

### 2.1 종류

데이터베이스와 대화하기 위한 표준 언어.

* **DDL (정의어)**: 테이블 구조를 만들거나 수정한다 (CREATE, ALTER, DROP).
* **DML (조작어)**: 데이터를 넣고 빼고 수정한다 (INSERT, UPDATE, DELETE).
* **DQL (질의어)**: 데이터를 조회한다 (SELECT).
* **TCL (제어어)**: 작업을 확정하거나 취소한다 (COMMIT, ROLLBACK).

### 2.2 키(Key)와 무결성 제약 조건

데이터를 식별하고 테이블 간의 관계를 맺기 위해 키를 사용.

* **기본키(Primary Key)**: 각 데이터를 유일하게 식별하는 대표 키다. 절대 중복될 수 없고 비어있을 수도 없다.
* **외래키(Foreign Key)**: 다른 테이블을 참조하기 위해 연결 고리 역할을 하는 키.
* **무결성 규칙**:

  * **개체 무결성**: 기본키는 중복되거나 비어있으면 안 된다는 규칙.
  * **참조 무결성**: 외래키는 반드시 참조하는 테이블에 실제로 존재하는 값을 가져야 한다는 규칙.

### 2.3 SELECT 문

#### 실행 순서 이해하기

우리가 작성하는 순서와 실제 컴퓨터가 처리하는 순서가 다르다!

* **작성 순서**: SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY
* **처리 순서**: **FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY**

#### 데이터 정렬 (ORDER BY)

* **ASC**: 오름차순(기본값)이다. 작은 값부터 큰 값 순으로 보여준다.
* **DESC**: 내림차순이다. 큰 값부터 작은 값 순으로 보여준다.
* **특징**: 컬럼 이름 대신 별칭(Alias)이나 컬럼의 순서 번호를 써도 정렬된다.

#### 조건에 맞는 데이터 찾기 (WHERE)

* **비교**: `=`, `>`, `<` 등을 사용한다. 문자와 날짜는 작은 따옴표(`' '`)로 감싸야 한다.
* **NULL 찾기**: 데이터가 비어있는지 확인할 때는 `=`이 아니라 `IS NULL`을 써야 한다.
* **논리**: 여러 조건을 합칠 때 `AND`(그리고)와 `OR`(또는)를 사용한다.

#### 유용한 조회 기능들

* **별칭(Alias)**: 컬럼 이름이 어려우면 `AS`를 써서 쉬운 이름을 붙여 출력할 수 있다.
* **패턴 검색(LIKE)**: `%`는 글자 수 상관없이 일치, `_`는 한 글자만 일치를 의미한다. (예: `LIKE '정%'`는 '정'으로 시작하는 모든 이름을 찾는다.)
* **범위(BETWEEN)**: 특정 범위 사이의 값을 찾는다 (예: `BETWEEN 10 AND 20`).
* **목록(IN)**: 여러 값 중 하나라도 포함된 데이터를 찾는다.
* **제한(LIMIT)**: 보여줄 데이터의 개수를 정한다. (예: `LIMIT 5`는 상위 5개만 보여준다.)

## 3. 데이터베이스 함수 (Function)

입력 데이터를 연산하여 **결과값을 만드는 객체**. 프로그래밍 언어의 함수와 달리 반드시 값을 리턴한다. 원본 데이터를 변경하지 않는다.

### 3.1 주요 함수 종류

* **스칼라 함수 (Scala Function)**: 데이터 1개를 입력하면 결과 1개를 리턴.
* **집계 함수 (Grouping Function)**: 여러 데이터를 묶어 합계, 평균 등의 통계를 계산.
* **시스템 함수 (System Function)**: 타입 변환이나 NULL 처리 등 시스템적인 연산을 수행.

### 3.2 자주 쓰는 내장 함수

* **수치 함수**: 

  * `ROUND`: 반올림을 수행하며 자릿수를 지정할 수 있다.
  * `FLOOR`: 소수점을 버린다.
  * `MOD`: 나머지를 리턴한다. (예: 사원번호가 홀수인지 판별할 때 활용)
* **문자열 함수**:

  * `CHAR_LENGTH`: 글자 수를 계산한다.
  * `LENGTH`: 바이트 수를 계산한다. (한글은 글자당 바이트가 다르므로 주의)
  * `SUBSTRING`: 문자열의 특정 위치부터 원하는 개수만큼 잘라낸다.
  * `TRIM`: 문자열 앞뒤의 공백을 제거한다.
* **날짜 함수**:

  * `NOW()`, `CURDATE()`: 현재 시간과 날짜를 가져온다.
  * `DATEDIFF`: 두 날짜 사이의 차이를 계산한다.
  * `STR_TO_DATE`: 문자열을 날짜 형식으로 변환한다.

### 3.3 데이터 그룹화와 집계 (Grouping)

데이터를 특정 기준(부서, 직무 등)으로 묶어 통계를 내는 핵심 기술.

* **집계 함수 (Aggregate Function)**

  * **COUNT**: 데이터 개수를 세며, NULL인 데이터는 제외한다. 전체 행을 셀 때는 `COUNT(*)`를 사용한다.
  * **SUM / AVG**: 합계와 평균을 구한다. 숫자형 컬럼에만 사용 가능하다.
  * **MAX / MIN**: 최대값과 최소값을 구한다.
* **GROUP BY와 HAVING**

  * **GROUP BY**: 컬럼의 값이 동일한 데이터끼리 모아서 처리한다. 
  * **HAVING**: 그룹화가 완료된 결과물에 조건을 걸 때 사용한다. (예: 인원수가 3명 이상인 부서만 조회)

### 3.4 윈도우 함수 (Window Function)

행과 행 사이의 관계를 정의하여 순위를 매기거나 분석할 때 사용.

* **순위 함수**:

  * **ROW_NUMBER**: 중복 없이 무조건 1번부터 번호를 매긴다.
  * **DENSE_RANK**: 공동 순위가 있어도 다음 번호를 건너뛰지 않는다 (1, 2, 2, 3).
  * **RANK**: 공동 순위가 있으면 다음 번호를 건너뛴다 (1, 2, 2, 4).
* **분석 함수**:

  * **LEAD / LAG**: 다음 행이나 이전 행의 데이터를 가져온다. 행 간의 데이터 차이를 계산할 때 유용하다.

### 3.5 서브쿼리 (Sub Query)
하나의 SQL 문장 안에 포함된 또 다른 SQL 문. 반드시 괄호`()`로 감싸야 하며 연산자의 오른쪽에 위치한다.

#### 리턴 결과에 따른 분류
* **단일 행 서브쿼리**: 결과가 오직 1개인 경우로, `=`, `>`, `<` 등의 일반 비교 연산자를 사용한다.
* **다중 행 서브쿼리**: 결과가 여러 줄인 경우로, 전용 연산자를 사용해야 한다.
  * **IN**: 결과 목록 중 하나라도 일치하면 참이다.
  * **ALL**: 결과 목록의 모든 값보다 커야(혹은 작아야) 참이다. (최대/최소값과 비교하는 것과 같음)
  * **ANY / SOME**: 결과 목록 중 하나라도 조건을 만족하면 참이다.
  * **EXISTS**: 결과가 존재하는지만 확인하여 참/거짓을 리턴한다.
* **다중 열 서브쿼리**
 * 서브쿼리가 여러 개의 컬럼을 리턴하는 경우다. `WHERE (컬럼1, 컬럼2) = (SELECT 컬럼1, 컬럼2 ...)` 형식으로 한꺼번에 비교 가능하다.

## 4. 조인 (JOIN)

두 개 이상의 테이블을 가로 방향으로 합쳐서 여러 컬럼을 한 번에 추출하는 연산.

* **CROSS JOIN**: 두 테이블의 모든 가능한 조합을 만든다. (카테시안 곱)
* **EQUI JOIN**: 동일한 의미를 가진 컬럼의 값이 일치할 때 데이터를 합친다. (가장 많이 사용)
* **NON EQUI JOIN**: `=` 이외의 연산자(BETWEEN 등)를 사용하여 데이터를 합친다.
