## 1. 계층별 주소 체계와 동작
네트워크 통신은 각 계층의 고유한 주소를 기반으로 데이터를 처리한다.

### 1) MAC 주소 (2계층)
하드웨어 제조업체에서 고정하여 출하하는 물리적 주소다.
* **구조**: 48비트의 16진수 12자리로 표현된다.
    - **OUI (앞 24비트)**: 제조사 식별 코드.
    - **UAA (뒤 24비트)**: 제조사에서 부여한 고유 번호.
* **동작**: 랜카드(NIC)는 전기 신호를 데이터로 변환한 후, 목적지 MAC 주소가 자신의 것과 일치하면 처리하고 아니면 폐기한다. 단, 분석 용도인 **무차별 모드**에서는 모든 패킷을 처리하기도 한다.

### 2) IP 주소 (3계층)
사용자가 변경 가능한 논리적 주소로, 네트워크 주소와 호스트 주소로 나뉜다.
* **IPv4 클래스 분류**:
    - **A 클래스**: 대규모 네트워크 (0.0.0.0 ~ 127.255.255.255)
    - **B 클래스**: 중규모 네트워크 (128.0.0.0 ~ 191.255.255.255)
    - **C 클래스**: 소규모 네트워크 (192.0.0.0 ~ 223.255.255.255)
* **특수 주소**: 네트워크를 대표하는 **첫 번째 주소**와 해당 네트워크 전체에 데이터를 뿌리는 **마지막 주소(브로드캐스트)**는 호스트 IP로 사용할 수 없다.
* **Bogon IP**: IANA에서 예약해 놓은 주소로, 이 대역에서 통신 시도가 있다면 해킹(IP Spoofing) 가능성이 크다.

## 2. 주소 변환 프로토콜: ARP
논리 주소(IP)를 물리 주소(MAC)로 바꾸어 실제 통신 경로를 찾는 과정이다.

* **ARP (Address Resolution Protocol)**: 목적지 IP는 알지만 MAC 주소를 모를 때, 브로드캐스트를 통해 상대방의 응답을 받아 MAC 주소를 알아내는 프로토콜이다.
* **GARP (Gratuitous ARP)**: 자신의 IP와 MAC 주소를 네트워크에 알릴 목적으로 사용한다. 주로 **IP 주소 충돌 감지**를 위해 내 IP가 이미 사용 중인지 확인할 때 쓰인다.
* **RARP**: MAC 주소는 알지만 IP를 모를 때 사용하며, 현재는 기능이 확장된 **DHCP**로 대체되었다.

## 3. 전송 계층의 통신 제어 (4계층)
데이터가 목적지 프로세스에 정확히 도달하도록 관리한다.

* **포트(Port) 분류**:
    - **Well Known 포트**: 0~1023번 (HTTP: 80, HTTPS: 443 등).
    - **등록된 포트**: 1024~49151번 (일반 애플리케이션용).
    - **동적/임시 포트**: 49152~65535번.
* **TCP와 UDP의 차이**:
    - **TCP**: 연결 지향형으로 순서 보장, 오류 제어, 흐름 제어를 수행한다. (Full Duplex 방식)
    - **UDP**: 비연결형으로 오류 제어를 하지 않으며 실시간 트래픽 전송에 최적화되어 있다. (Half Duplex 방식)

## 4. 스위치(Switch) 장비의 동작 원리
2계층 주소인 MAC 주소를 기반으로 패킷의 흐름을 중재한다.

### 1) MAC 주소 테이블 관리 단계
* **Address Learning**: 들어오는 패킷의 출발지 MAC 주소와 연결된 포트 번호를 테이블에 기록한다.
* **Flooding**: 목적지 주소를 모를 때, 들어온 포트를 제외한 모든 포트로 데이터를 전송한다.
* **Forwarding/Filtering**: 목적지 위치를 알면 해당 포트로만 데이터를 보내고(Forwarding), 나머지 포트로는 보내지 않는다(Filtering).


### 2) VLAN (가상 랜)
물리적 스위치 한 대를 논리적으로 쪼개어 여러 네트워크처럼 사용하는 기술이다.
* **특징**: VLAN 간에는 유니캐스트와 브로드캐스트 모두 차단되므로, 서로 통신하려면 반드시 3계층 장비(라우터 등)를 거쳐야 한다.
* **Trunk(Tagged) 포트**: 하나의 물리 포트를 통해 여러 개의 VLAN 데이터를 한꺼번에 주고받을 수 있도록 설정한 포트다.

### 3) 기타 기술
* **STP (Spanning Tree Protocol)**: 네트워크의 물리적 연결이 루프(Loop) 형태일 때 발생하는 무한 뺑뺑이 현상을 방지하는 프로토콜이다.
* **SPoF (Single Point of Failure)**: 단 한 곳의 고장이 전체 시스템 마비를 일으키는 '단일 장애점'을 의미하며, 이를 방지하기 위한 이중화 설계가 중요하다.
