## 1. 정보 보안 개요
정보 보안이란 인가된 사용자만이 정확한 정보에 필요할 때 접근할 수 있도록 보장하는 일련의 과정을 의미한다.

### 1) 정보 보안의 필수 3요소 (CIA)
* **기밀성 (Confidentiality)**: 인가되지 않은 사용자가 정보를 열람하지 못하게 제한한다.
* **무결성 (Integrity)**: 정보가 정확하고 완전하게 유지되도록 보호한다.
* **가용성 (Availability)**: 정보가 필요할 때 지체 없이 접근할 수 있도록 보장한다.

### 2) 네트워크 보안 구역
* **Trust Network**: 보안 정책에 의해 관리되는 내부 네트워크다.
* **Untrust Network**: 신뢰할 수 없는 외부 인터넷 영역이다.
* **DMZ (Demilitarized Zone)**: 외부 사용자에게 개방해야 하는 서비스(웹 서버 등)가 위치하는 중간 구역이다.

---

## 2. 주요 보안 솔루션의 종류
다양한 위협에 대응하기 위해 각 계층별로 전문화된 보안 장비를 운용한다.

* **DDoS 방어 장비**: 대규모 트래픽으로 서비스를 마비시키는 DDoS 공격을 완화한다. 주로 회선 인입부에서 과도한 트래픽을 필터링한다.
* **IDS/IPS**: 침입 탐지(IDS) 및 방지(IPS) 시스템이다. 공격 데이터베이스(패턴)를 기반으로 패킷을 분석하여 유해한 통신을 차단한다.
* **WAF (Web Application Firewall)**: 웹 서버 전용 보안 장비다. HTTP/HTTPS 프로토콜을 정밀하게 분석하여 IPS가 놓치기 쉬운 웹 전용 공격을 방어한다.
* **NAC (Network Access Control)**: 네트워크 접속 제어 기술이다. 인가된 단말기만 내부망에 접속할 수 있도록 제어하여 보안 사고를 예방한다.
* **VPN (Virtual Private Network)**: 공용망을 전용선처럼 사용할 수 있게 해주는 가상 사설망이다. 데이터 암호화와 터널링 기법을 통해 안전한 통로를 구축한다.

## 3. 방화벽 (Firewall)의 동작 원리
방화벽은 네트워크 3, 4계층에서 동작하며, 설정된 정책에 따라 트래픽의 허용 및 차단 여부를 결정한다.

* **상태 기반 엔진 (SPI)**: 현대적 방화벽의 핵심 기능이다. 패킷 하나만 보는 것이 아니라 통신의 흐름(세션)을 인지하여, 내부에서 요청한 것에 대한 응답 패킷은 자동으로 허용하는 지능형 필터링을 수행한다.
* **ALG (Application Layer Gateway)**: FTP와 같이 데이터 전송 시 포트 번호가 동적으로 변하는 프로토콜을 이해하여, 방화벽이 필요한 포트를 자동으로 개방해 주는 기술이다.

## 4. 리눅스 서버 보안 및 로그 관리
시스템의 모든 활동 기록인 로그를 분석함으로써 사고의 원인을 규명하고 침입 경로를 추적할 수 있다.

### 1) 주요 시스템 로그 파일 (/var/log)
* **syslog**: 커널이나 데몬에서 발생하는 대부분의 공통적인 메시지가 기록된다.
* **auth.log / btmp**: 로그인 성공 및 실패 등 인증과 관련된 기록을 담는다.
* **lastlog**: 각 계정의 가장 최근 로그인 정보를 저장한다.
* **wtmp**: 전체 로그인 정보를 기록하며 `last` 명령어로 확인 가능하다.

### 2) 로그 관리 시스템 (rsyslog & journald)
* **rsyslog**: 규칙 기반의 로그 관리 데몬이다. '기능.우선순위' 형태의 필터를 사용하여 특정 로그를 별도의 파일로 저장하거나 관리자에게 알림을 보낼 수 있다.
* **journald (systemd-journald)**: systemd의 구성 요소로, 바이너리 형태의 로그(저널)를 관리한다. 텍스트로 수정할 수 없어 보안성이 높으며 `journalctl` 명령어를 통해 상세히 조회할 수 있다.

### 3) 서버 보안의 기본 조치
* **최소 권한 원칙**: 불필요한 서비스 포트를 닫고 꼭 필요한 서비스만 개방한다.
* **주기적 패치**: 최신 보안 업데이트를 지속적으로 수행하여 시스템 취약점을 보완한다.
* **정기 백업**: 사고 발생 시 시스템을 복구할 수 있도록 주요 데이터와 설정을 주기적으로 백업한다.
