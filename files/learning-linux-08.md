## 1. 네트워크 관리 프로토콜 및 서버 설정
리눅스 시스템에서 제공하는 주요 네트워크 서비스들의 구성과 관리 방법이다.

### 1) 파일 송수신 (FTP)
* **서버 관리**: `vsftpd` 패키지를 사용하며, 설정 파일은 `/etc/vsftpd.conf`다. `telnet 0 21` 명령으로 서버 동작 여부를 확인할 수 있다.
* **주요 명령어**:
    - `get / put`: 원격 호스트의 파일을 다운로드하거나 로컬 파일을 업로드한다.
    - `mget / mput`: 여러 개의 파일을 한꺼번에 전송한다.
    - `lcd / !ls`: 로컬 디렉토리 이동 및 파일 목록을 확인한다 (명령어 앞에 `!`를 붙이면 로컬 명령을 수행한다).

### 2) 메일 및 데이터베이스 서버
* **메일 서버**: `mailutils` 패키지를 사용하며 기본 25번 포트를 이용한다. `mailx` 명령어로 메일을 보내거나 읽을 수 있다.
* **DB 서버 (MariaDB)**: `mariadb-server` 패키지를 설치하여 운영한다. 외부 접속을 허용하려면 설정 파일(`/etc/mysql/mariadb.conf.d/50-server.cnf`)에서 `bind-address`를 `0.0.0.0`으로 수정해야 한다.

### 3) 웹 서버 (Apache)
* **설치 및 구동**: `sudo apt install apache2`로 설치하며 서비스 이름은 `apache2`다.
* **보안 및 경로**: `ufw` 명령어로 방화벽 상태를 관리하며, 기본 웹 페이지 파일(index.html)은 `/var/www/html` 디렉토리에 위치한다.

## 2. 셸 프로그래밍 (Shell Programming)
셸 스크립트는 리눅스 명령어와 프로그래밍 제어문을 결합하여 시스템 작업을 자동화하는 인터프리터 기반 스크립트 언어다.

### 1) 기본 작성 및 실행
* **셔뱅(Shebang)**: 스크립트 최상단에 `#!/bin/bash`를 작성하여 해당 파일을 해석할 셸의 경로를 지정한다.
* **변수 선언**: `변수명=값` 형태로 선언하며, 등호(`=`) 앞뒤에 공백이 없어야 한다. 사용할 때는 `$변수명` 형식을 취한다.

### 2) 변수의 종류와 매개변수
* **지역 변수**: 함수 내부에서 `local` 예약어와 함께 선언하여 해당 함수 안에서만 사용한다.
* **위치 매개변수**:
    - `$0`: 실행된 스크립트 파일의 이름
    - `$1 ~ $9`: 인자로 전달된 값 ($10부터는 `${10}` 형식을 사용)
    - `$#`: 전달된 파라미터의 개수
    - `$* / $@`: 전달된 파라미터 전체


### 3) 제어문 (조건문 및 반복문)
* **if문**: `if [ 조건식 ]` 형태로 작성하며, 조건식의 대괄호와 내용 사이에는 반드시 공백이 있어야 한다.
* **case문**: 여러 조건을 비교할 때 사용하며 `esac`로 종료한다.
* **반복문 (for / while)**:
    - **for**: 정해진 범위나 리스트에 대해 루프를 수행한다.
    - **while**: 조건식이 참인 동안 계속해서 명령을 반복 실행한다.

### 4) 주요 연산자
* **문자열 비교**: `-z`(길이가 0이면 참), `-n`(길이가 0이 아니면 참).
* **숫자 비교**: `-eq`(같음), `-ne`(다름), `-gt`(큼), `-ge`(크거나 같음), `-lt`(작음), `-le`(작거나 같음).
