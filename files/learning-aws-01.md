## 1. AWS(Amazon Web Services) 개요
AWS는 전 세계적으로 가장 널리 사용되는 퍼블릭 클라우드 서비스로, 인프라 구축에 필요한 다양한 기능을 모듈식으로 제공한다.

### 1) 주요 특징
* **서비스 조합의 용이성**: 내부 서비스뿐만 아니라 외부 시스템과의 연동이 쉽다.
* **종량제 요금**: 사용한 리소스만큼 지불하며, 한국 원화 결제 및 전담 지원 팀(APN 파트너)을 통한 컨설팅이 가능하다.
* **보안 및 규정 준수**: 한국 정보보호 관리체계(ISMS) 인증을 취득하여 안정성을 보장한다.
* **글로벌 확장성**: 전 세계에서 가장 많은 리전(Region)과 인프라 거점을 보유하고 있다.

### 2) 핵심 서비스 구성
* **컴퓨팅**: EC2(가상 서버), EKS(쿠버네티스), ECS(컨테이너 서비스)
* **스토리지**: S3(오브젝트 스토리지), S3 Glacier(장기 보관), EBS(인스턴스용 디스크)
* **네트워크**: VPC(가상 네트워크), Route 53(DNS), Elastic IP(정적 IP)
* **데이터베이스**: RDS(관계형 DB)
* **개발자 도구**: Cloud9(웹 기반 IDE), CodeBuild, CodePipeline(DevOps)

## 2. 클라우드 인프라 기본 개념
* **리전(Region)**: AWS 서비스가 위치한 물리적인 장소다. 속도 향상을 위해 사용자와 가까운 곳을 선택하는 것이 유리하다.
* **가용 영역(AZ)**: 리전 내에 존재하는 독립된 데이터 센터다. 고가용성을 위해 여러 AZ에 서버를 분산 배치하는 것이 권장된다.
* **에지 로케이션(Edge Location)**: 콘텐츠 전송 네트워크(CDN) 서비스인 CloudFront를 위한 캐시 서버 거점이다.
* **VPC(Virtual Private Cloud)**: AWS 계정 전용 가상 네트워크로, 논리적으로 격리된 환경을 제공한다.
* **보안 그룹(Security Group)**: 가상의 방화벽 역할을 하며, 인바운드와 아웃바운드 트래픽에 대한 포트 및 IP 대역을 제어한다.

## 3. EC2(Elastic Compute Cloud) 실습
가장 기본적인 가상 서버 서비스로, 사용자가 운영체제와 소프트웨어를 직접 관리하는 형태다.

### 1) 인스턴스 생성 절차
1.  **AMI 선택**: 사용할 운영체제 이미지(예: Ubuntu)를 선택한다.
2.  **인스턴스 유형 선택**: 필요한 CPU 및 메모리 사양을 결정한다.
3.  **키 페어(Key Pair) 생성**: SSH 원격 접속을 위한 인증키를 다운로드한다.
4.  **네트워크 및 보안 그룹 설정**: 외부 접속을 위해 포트(22, 80 등)를 개방한다.
5.  **스토리지 설정**: 데이터 저장소인 EBS의 용량을 지정한다.

### 2) 원격 접속 및 서버 설정
* **SSH 접속**: `ssh -i "키페어경로" ubuntu@PublicIP` 명령을 통해 접속한다.
* **웹 서버(Apache) 설치**:
  - 패키지 업데이트: `sudo apt update`
  - 설치: `sudo apt install -y apache2`
  - 보안 그룹에서 80번 포트 개방 후 웹 브라우저 접속 확인
* **데이터베이스(MySQL) 설치 및 설정**:
  - 설치: `sudo apt install mysql-server`
  - 루트 계정 비밀번호 변경 및 `bind-address=0.0.0.0` 설정을 통해 외부 접속 허용 처리
  - 변경 사항 적용을 위해 `FLUSH PRIVILEGES` 명령 수행 및 서비스 재시작

## 4. 비용 및 관리 도구
* **AWS Billing**: 요금 예측 및 예산 초과 시 알림 설정이 가능하다.
* **프리 티어(Free Tier)**: 가입 후 12개월간 소규모 인스턴스(EC2, RDS 등)와 5GB의 S3 스토리지를 무료로 이용할 수 있다.
* **AWS CLI**: 로컬 터미널에서 명령어나 스크립트로 AWS 서비스를 제어할 수 있는 도구다.
