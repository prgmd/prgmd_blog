## 1. 우분투 패키지 관리 시스템
리눅스 소프트웨어는 소스 코드 형태나 설치가 간편한 패키지 형태로 제공된다. 우분투는 기본적으로 **deb** 패키지 형식을 사용한다.

### 1) 패키지 관리 도구: APT와 dpkg
* **APT (Advanced Package Tool)**: 인터넷 저장소에서 패키지를 내려받아 의존성 문제를 자동으로 해결하며 설치해 주는 도구다. 
    - `apt update`: 저장소의 최신 패키지 정보를 가져온다.
    - `apt install [패키지]`: 소프트웨어를 설치한다.
    - `apt purge [패키지]`: 설정 파일까지 포함하여 완전히 삭제한다.
* **dpkg**: 인터넷 연결 없이 이미 가지고 있는 `.deb` 파일을 직접 설치하거나 시스템의 세부 패키지 정보를 확인할 때 사용한다.

### 2) 새로운 패키지 형식: snap
우분투 16.04부터 도입된 샌드박스 형식의 패키지다.
* **장점**: 실행에 필요한 모든 라이브러리를 포함하고 있어 의존성 충돌이 없으며 보안이 강력하다.
* **단점**: 필요한 라이브러리를 중복으로 포함하기 때문에 패키지 용량이 커진다.
* **설치 위치**: snap으로 설치된 프로그램은 `/snap` 디렉토리 아래에 위치한다.

## 2. 파일 아카이브 및 압축
여러 파일을 하나로 묶는 '아카이브'와 용량을 줄이는 '압축'은 리눅스 환경에서 빈번하게 일어나는 작업이다.

### 1) tar (Tape Archive)
파일들을 하나로 묶어주는 가장 대표적인 명령이다.
* **주요 기능**:
    - `cvf`: 새로운 아카이브 파일을 생성한다.
    - `xvf`: 묶인 파일을 푼다.
    - `tvf`: 내용을 미리 확인한다.
* **압축 결합**: `z` 옵션을 붙이면 gzip으로, `j` 옵션을 붙이면 bzip2 방식으로 묶음과 동시에 압축을 진행한다.

### 2) 압축 도구 (gzip, bzip2)
* **gzip**: 속도가 빠르며 가장 널리 쓰인다. 압축 시 `.gz` 확장자가 붙는다.
* **bzip2**: gzip보다 압축률이 우수하지만 처리 속도가 상대적으로 느리다. 압축 시 `.bz2` 확장자가 붙는다.

## 3. C 언어 프로그래밍 및 컴파일
리눅스 시스템 프로그래밍의 기초인 C 언어 소스 코드를 실행 파일로 만드는 과정이다.

### 1) gcc 컴파일러
리눅스의 표준 C 컴파일러다.
* **컴파일**: `gcc hello.c` 명령을 내리면 `a.out`이라는 기본 실행 파일이 생성된다.
* **실행**: 보안상 현재 디렉토리가 PATH에 포함되어 있지 않으므로 `./a.out`과 같이 경로를 명시해야 실행된다.
* **이름 지정**: `-o` 옵션을 사용해 `gcc -o hello hello.c`와 같이 실행 파일 이름을 지정할 수 있다.

### 2) 빌드 자동화 도구: make
수많은 소스 파일로 구성된 프로젝트를 일일이 컴파일하는 번거로움을 해결해 준다.
* **makefile**: 컴파일 순서와 규칙을 기록한 설정 파일이다.
* **동작 원리**: `make` 명령만 입력하면 설정된 규칙에 따라 변경된 파일만 골라 효율적으로 빌드하고 실행 파일을 생성한다.
