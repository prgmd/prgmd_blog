## 1. 리눅스(Linux) 시스템 개요
리눅스는 리누스 토발즈가 유닉스를 참조하여 개발한 오픈 소스 운영체제다. 윈도우와 달리 소스코드가 공개되어 있어 다양한 버전(배포판)으로 발전해 왔다.

### 1) 리눅스의 내부 구조
* **커널(Kernel)**: 하드웨어 자원을 직접 제어하고 관리하는 가장 핵심적인 부분이다.
* **셸(Shell)**: 사용자가 입력한 명령을 해석해 커널에 전달하는 번역기 역할을 한다.
* **애플리케이션(Application)**: 사용자에게 특정 기능을 제공하는 프로그램 층이다.



### 2) 가상화와 접속 환경
* **가상화**: 하나의 컴퓨터에서 여러 운영체제를 동시에 돌리는 기술이다. Virtual Box 같은 도구를 사용한다.
* **NAT**: 가상 머신이 외부 인터넷과 통신하기 위해 IP를 변환하는 기술이다.
* **SSH**: 원격 서버에 안전하게 접속하기 위한 보안 프로토콜이다. 리눅스 서버 관리에 필수적이다.

## 2. 터미널 프롬프트와 명령어 기초
리눅스는 텍스트 기반의 명령어를 통해 시스템을 제어한다.

* **프롬프트 구성**: `사용자명@호스트명:현재디렉토리$` 형태다.
* **사용자 구분**: 끝 기호가 `$`이면 일반 사용자, `#`이면 모든 권한을 가진 슈퍼 사용자(Root)를 의미한다.
* **명령어 구조**: `명령어 [옵션] [인자]` 순서로 입력하며 공백으로 구분한다. 옵션은 보통 `-`(한 글자)나 `--`(단어)로 시작한다.

### 💡 유용한 기본 명령어
* **ls**: 현재 디렉토리의 파일 목록을 보여준다.
* **history**: 이전에 입력했던 명령어 목록을 확인한다. `!!`를 치면 바로 직전 명령을 다시 실행한다.
* **sudo**: 관리자 권한을 잠시 빌려 명령을 수행한다.
* **man**: 특정 명령어의 사용법(매뉴얼)을 상세히 보여준다.

## 3. Vim 편집기 마스터하기
Vim은 리눅스에서 가장 널리 쓰이는 화면 단위 편집기다. 마우스 없이 키보드 모드 전환만으로 모든 편집을 수행한다.

### 1) 3가지 주요 모드
* **명령 모드 (Command Mode)**: 처음 파일을 열었을 때의 상태다. 커서 이동, 삭제, 복사가 가능하다.
* **입력 모드 (Insert Mode)**: `i`나 `a`를 눌러 진입하며, 실제로 글자를 타이핑하는 모드다. `ESC`를 누르면 다시 명령 모드로 돌아온다.
* **마지막 행 모드 (Last-line Mode)**: `:`를 눌러 진입하며, 파일 저장(`:w`)이나 종료(`:q`)를 수행한다.



### 2) 필수 단축키 요약
* **이동**: `h, j, k, l` (왼쪽, 아래, 위, 오른쪽) 키로 커서를 옮긴다.
* **삭제**: `x`는 한 글자 삭제, `dd`는 한 줄 전체를 삭제한다.
* **복사 및 붙여넣기**: `yy`로 줄을 복사하고 `p`로 커서 아래에 붙여넣는다.
* **취소**: 실수했을 때 `u`를 누르면 이전 작업이 취소된다.

### 3) 버퍼(Buffer) 이해하기
복사하거나 잘라낸 내용은 '버퍼'라는 임시 공간에 담긴다. 기본적으로 하나의 내용만 기억하는 '언네임드 버퍼'를 쓰지만, 이름을 붙인 '네임드 버퍼'를 사용하면 여러 문장을 따로 저장해 두고 골라서 붙여넣을 수 있다.
