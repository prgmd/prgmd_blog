## 1. 객체 지향 프로그래밍(OOP)의 이해
프로그램을 단순한 명령어의 나열이 아니라, 하나의 '객체'라는 단위로 나누어 설계하는 방식이다.

### 💡 주요 특징 4가지
* **캡슐화(Encapsulation):** 목적이 같은 데이터와 함수를 하나로 묶어 보호하는 기능이다.
* **상속(Inheritance):** 부모 클래스의 유전자를 자식 클래스가 그대로 물려받아 재사용하는 성질이다.
* **다형성(Polymorphism):** 똑같은 이름의 명령이라도 어떤 객체가 실행하느냐에 따라 다르게 반응하는 특징이다.
* **동적 바인딩(Dynamic Binding):** 프로그램이 돌아가는 도중에 메서드 호출을 유연하게 변경할 수 있다.

### 📒 핵심 용어 정리
| 용어 | 설명 |
| :--- | :--- |
| **객체(Object)** | 프로그래밍에서 사용되는 모든 실체 |
| **클래스(Class)** | 객체를 만들기 위한 묶음(설계도) |
| **인스턴스(Instance)** | 설계도를 바탕으로 메모리에 실제 구현된 실례 |
| **메서드(Method)** | 클래스 내부에 정의된 기능(함수) |
| **속성(Attribute)** | 클래스 내부에 저장된 데이터(변수) |

## 2. 메서드(Method)와 self
파이썬에서 메서드를 만들 때는 특별한 규칙이 있다.

* **인스턴스 메서드 생성:** 첫 번째 매개변수는 무조건 '나 자신'의 ID를 받는 변수여야 한다. 관례적으로 `self`라는 이름을 사용한다.
* **Bound 호출:** `인스턴스.메서드()` 형태로 호출하면 `self`에 주소값이 자동으로 대입된다.
* **Static & Class Method:**
    * **Static:** `@staticmethod` 데코레이터를 사용하며 `self`가 필요 없다. 인스턴스 속성에 접근할 수 없다.
    * **Class:** `@classmethod` 데코레이터를 사용하며 클래스 자신을 가리키는 `cls` 매개변수를 가진다.

## 3. 속성(Attribute)과 데이터 보호
데이터를 안전하게 관리하기 위해 클래스 외부에서 속성에 직접 접근하는 것은 피하는 것이 좋다.

* **클래스 속성:** 메서드 밖에서 선언하며 모든 인스턴스가 공유한다. 인스턴스로는 읽기만 가능하다.
* **인스턴스 속성:** 메서드 안에서 `self.변수`로 생성하며 해당 인스턴스만 개별적으로 가진다.
* **접근자(Accessor):**
    * **Getter:** 속성값을 읽어오는 메서드. 보통 `get속성명` 형식을 쓴다.
    * **Setter:** 속성값을 수정하는 메서드. `setScore`처럼 잘못된 데이터가 들어오지 않게 검증 로직을 넣을 수 있다.
* **Private 멤버:** 이름 앞에 밑줄 두 개(`__`)를 붙이면 클래스 외부에서 직접 접근할 수 없게 숨겨진다.

## 4. 메모리 관리와 가비지 컬렉션(GC)
파이썬은 메모리 청소를 자동으로 해주는 아주 착한 언어다.

* **레퍼런스 카운트(Reference Count):** 데이터를 가리키는 변수가 몇 개인지를 세는 방식이다.
* **해제 원리:** 참조 횟수가 0이 되면 메모리에서 자동으로 지워진다.
* **확인 방법:** `sys.getrefcount(객체)`를 통해 확인 가능하지만, 함수 호출 시 참조가 발생하므로 결과가 실제보다 1 높게 나온다는 점을 기억하자.

## 5. 상속(Inheritance)과 추상화
코드를 재사용하고 구조를 체계적으로 잡기 위해 상속을 사용한다.

* **메서드 오버라이딩:** 부모의 기능이 부족할 때 자식 클래스에서 내용을 다시 정의하는 것이다. 이때 `super().메서드()`를 써서 부모의 원래 기능을 호출하고 추가 내용을 작성하는 것이 일반적이다.
* **추상 클래스(Abstract Class):** `abc` 모듈을 사용하며 직접 객체를 만들 수 없는 '가이드라인' 역할을 하는 클래스다. 하위 클래스에서 반드시 특정 메서드를 구현하도록 강제할 때 쓴다.

## 6. 시퀀스 데이터 타입(Sequential Type)
데이터를 순서대로 나열하는 자료형들의 특징이다.

* **분류:**
    * **컨테이너:** list, tuple 등 (모든 자료형 저장 가능)
    * **균일:** str, bytes 등 (동일 자료형만 저장해 실제 데이터를 직접 담음)
* **공통 연산:**
    * **인덱싱/슬라이싱:** `[ ]`나 `[시작:끝:간격]`을 통해 원하는 부분을 가져온다.
    - **연결 및 반복:** `+`로 합치고 `*`로 반복할 수 있다.
    - **존재 확인:** `in` 명령어로 데이터가 들어있는지 바로 알 수 있다.
* **주요 클래스:**
    * **list:** 동적으로 크기가 변하며 데이터를 자유롭게 수정할 수 있다.
    * **tuple:** 리스트와 비슷하지만 한 번 만들면 내용을 절대 바꿀 수 없는 읽기 전용이다.
