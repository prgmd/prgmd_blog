## 1. 데이터베이스 영속성 관리 (MySQL)
컨테이너를 삭제하고 재생성하더라도 내부 데이터(DB)를 유지하기 위해 도커 볼륨을 활용한다. MySQL의 경우 데이터는 기본적으로 `/var/lib/mysql` 경로에 저장된다.

### 1) 볼륨 생성 및 컨테이너 연결
* **볼륨 생성**: `docker volume create mysql-data-vol`
* **컨테이너 실행**: 생성한 볼륨을 마운트하고 루트 비밀번호 및 초기 데이터베이스를 설정한다.
  ```bash
  docker run -dit --name=mysql-vtest -e MYSQL_ROOT_PASSWORD=비밀번호 -e MYSQL_DATABASE=DB이름 -v mysql-data-vol:/var/lib/mysql mysql
  ```
  
- 데이터 보존 확인: 컨테이너 접속 후 샘플 데이터를 생성한 뒤, 컨테이너를 중지(stop) 및 삭제(rm)하고 다시 동일한 볼륨으로 실행하여 데이터가 남아 있는지 확인한다.

## 2. 호스트 시스템과의 데이터 공유 (바인드 마운트)
컨테이너 내부에서 발생하는 로그나 설정 파일을 호스트 컴퓨터에서 직접 관리하기 위해 바인드 마운트를 사용한다.

### 1) Nginx 웹 서버 로그 저장 실습
- 호스트 디렉토리 준비: 로그를 저장할 로컬 폴더를 생성하고 절대 경로를 확인한다.
- 컨테이너 실행: Nginx의 로그 경로인 /var/log/nginx를 호스트의 폴더와 연결한다.

``` Bash
docker run -dit -p 80:80 -v /호스트/절대경로:/var/log/nginx nginx
```

- 결과: 웹 서버에 접속할 때마다 호스트의 지정된 폴더 내 access.log 파일에 실시간으로 로그가 기록되는 것을 확인할 수 있다.

## 3. 컨테이너 간 네트워크 연결 및 서비스 연동
여러 컨테이너가 서로 통신하기 위해서는 동일한 도커 네트워크에 소속되어야 한다.

### 1) 도커 네트워크 생성
- 컨테이너들이 서로를 식별하고 통신할 수 있는 가상 네트워크 환경을 만든다.
- 명령어: docker network create [네트워크명]

### 2) Redmine과 MySQL 연동 실습
- 개요: 프로젝트 관리 도구인 Redmine 컨테이너를 MySQL 데이터베이스 컨테이너와 연결한다.
- 절차:
  1. 사용자 정의 네트워크(예: redmine-net)를 생성한다.
  2. MySQL 컨테이너를 해당 네트워크(--net)에 포함시켜 실행한다. 이때 환경 변수로 Redmine에서 사용할 DB 정보를 설정한다.
  3. Redmine 컨테이너를 동일한 네트워크에 포함시키고, DB 호스트 정보 및 접속 계정을 설정하여 실행한다.
- 포트 포워딩: Redmine의 내부 포트(3000)를 호스트의 특정 포트와 매핑하여 외부 웹 브라우저에서 접근 가능하도록 설정한다.

## 4. 데이터베이스 내부 설정 (MySQL CLI)
컨테이너 내부 MySQL에 접속하여 외부 접근 권한을 부여하거나 사용자를 관리할 때 다음 과정을 수행한다.
- 컨테이너 접속: docker exec -it [컨테이너명] /bin/bash
- SQL 명령 수행:
  - 데이터베이스 생성: create database [이름];
  - 사용자 생성 및 권한 부여: grant all privileges on *.* TO '계정'@'%';
  - 변경 사항 적용: flush privileges;
