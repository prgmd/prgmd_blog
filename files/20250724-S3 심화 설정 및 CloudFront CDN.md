## 1. S3 버킷 심화 설정 및 앱 연동
Spring Boot 등 외부 애플리케이션에서 S3를 활용하기 위해서는 권한 및 네트워크 접근 제어가 필수적이다.

### 1) 버킷 정책(Bucket Policy) 및 퍼블릭 액세스
* **정책 정의**: JSON 형식을 사용하여 특정 버킷이나 객체에 대한 권한을 세밀하게 정의한다.
* **권한 설정 사례**: 외부에서 객체 목록 조회(List), 다운로드(Get), 업로드(Put), 삭제(Delete)를 허용하도록 정책을 구성할 수 있다.
* **Resource 지정**: 정책 적용 대상을 `arn:aws:s3:::버킷이름` 및 `/*` 형태로 지정하여 버킷 자체와 내부 객체 모두에 권한을 부여한다.

### 2) CORS(Cross-Origin Resource Sharing) 설정
* **개요**: 클라이언트 측 웹 애플리케이션(자바스크립트 등)에서 다른 도메인에 있는 S3 버킷으로 직접 요청을 보낼 때 브라우저 보안 정책에 의해 차단되지 않도록 설정하는 기능이다.
* **구성 항목**: 허용할 헤더(`AllowedHeaders`), HTTP 메서드(`GET`, `PUT`, `POST` 등), 허용할 출처(`AllowedOrigins`)를 배열 형태로 설정한다.

### 3) 애플리케이션 연동 정보
* 애플리케이션에서 S3에 접근하기 위해 `AWS_ACCESS_KEY`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION`, `AWS_S3_BUCKET` 정보를 환경 변수로 관리해야 한다.

## 2. CloudFront와 CDN(Content Delivery Network)
전 세계 사용자에게 최소한의 지연 시간으로 콘텐츠를 제공하기 위한 분산 네트워크 시스템이다.

### 1) CDN의 목적 및 동작 원리
* **지연 시간(Latency) 최소화**: 사용자와 물리적으로 멀리 떨어진 원본 서버(Origin Server)에서 데이터를 가져올 때 발생하는 네트워크 속도 저하 문제를 해결한다.
* **부하 분산**: 다수의 사용자가 동시에 요청하더라도 전 세계 거점에 분산된 서버가 대응하므로 안정적인 서비스 운영이 가능하다.

### 2) 핵심 구성 요소
* **오리진 서버 (Origin Server)**: 웹 사이트의 콘텐츠가 최초로 호스팅되는 원본 저장소다. (예: S3 버킷, EC2 서버)
* **에지 로케이션 (Edge Location)**: 전 세계 주요 도시에 위치한 캐시 서버 거점으로, 오리진의 콘텐츠 복사본을 저장한다.
* **전송 프로세스**: 사용자가 리소스를 요청하면 시스템은 사용자와 가장 가까운 에지 로케이션을 찾아 콘텐츠를 즉시 전달한다.

### 3) CloudFront 서비스의 장점
* AWS에서 제공하는 CDN 서비스로, 정적 콘텐츠뿐만 아니라 동적 콘텐츠의 가속 기능도 지원한다.
* 보안 기능(AWS WAF 등)과 연동이 쉬우며, 데이터 전송 효율을 극대화하여 사용자 경험을 향상시킨다.
