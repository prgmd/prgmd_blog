## 1. 쿠버네티스 로드 밸런서 (MetalLB)
퍼블릭 클라우드의 관리형 서비스가 없는 환경(온프레미스 등)에서 로드 밸런싱 기능을 사용하기 위해 MetalLB를 활용한다.

### 1) 설치 및 초기 설정
* **설치**: 매니페스트 방식을 통해 `metallb-system` 네임스페이스에 필요한 리소스를 생성한다.
* **IP 대역 설정 (IPAddressPool)**: 로드 밸런서 서비스에 할당할 외부 IP 주소 범위를 지정한다. (예: 172.31.40.1-172.31.40.31)
* **광고 설정 (L2Advertisement)**: 설정된 IP 풀을 네트워크 상에 알릴 수 있도록 L2 레이어 광고를 활성화한다.

### 2) 서비스 연동 테스트
* `type: LoadBalancer`로 서비스를 생성하면 MetalLB가 정의된 범위 내의 가상 IP를 자동으로 할당하며, 할당된 `External IP`를 통해 클러스터 외부에서 접근이 가능해진다.

## 2. Nginx 인그레스 (Ingress) 활용
클러스터 내부에서 L7 로드 밸런싱을 수행하기 위해 Nginx 인그레스 컨트롤러를 설치하고 라우팅 규칙을 설정한다.

### 1) 인그레스 컨트롤러 설치 및 확인
* 공식 레포지토리의 매니페스트를 적용하여 `ingress-nginx` 구성 요소를 배포하고 정상 구동 여부를 확인한다.

### 2) 라우팅 실습 구조
* **디플로이먼트 및 서비스**: 테스트용 HTTP 서버 파드를 생성하고 이를 연결하는 서비스를 구축한다.
* **호스트 기반 라우팅**: 요청 헤더의 `host` 필드(예: example1.com, example2.com)에 따라 서로 다른 백엔드 서비스로 트래픽을 분산한다.
* **경로 기반 라우팅**: 하나의 도메인 내에서 URL 패스(예: /backend1, /backend2)를 기준으로 트래픽을 분기 처리한다.

### 3) 로컬 접속 설정
* 테스트를 위해 로컬 PC의 `/etc/hosts` 파일에 워커 노드의 IP와 테스트용 도메인을 매핑하여 실제 도메인 서버 없이도 이름 기반 접속을 확인한다.
