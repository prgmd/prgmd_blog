## 1. 파일 시스템 권한 심화
리눅스에서는 기본적인 읽기/쓰기/실행 권한 외에도 시스템 운영을 위한 특수 권한 체계를 가지고 있다.

### 1) 기본 권한 설정 (umask)
파일이나 디렉토리를 생성할 때 자동으로 부여되는 초기 권한을 결정하는 값이다.
* **해석 방법**: 전체 권한(777)에서 마스크 값을 뺀 결과가 실제 권한이 된다.
* **보안상 특징**: 파일 생성 시 실행(x) 권한은 기본적으로 부여되지 않는데, 이는 악성 스크립트가 임의로 실행되는 것을 방지하기 위한 보안 조치다.

### 2) 특수 접근 권한
권한의 맨 앞자리에 숫자를 추가하여 특별한 기능을 부여한다.
* **SetUID (4)**: 파일을 실행하는 동안 사용자가 아닌 **파일 소유자의 권한**으로 실행된다. `passwd` 명령어가 대표적이며, 일반 사용자가 일시적으로 root 권한을 얻어 자신의 비밀번호를 변경할 수 있게 해준다.
* **SetGID (2)**: 실행하는 동안 파일 소속 그룹의 권한을 가진다.
* **스티키 비트 (Sticky Bit, 1)**: `/tmp` 디렉토리처럼 누구나 파일을 만들 수 있지만, 삭제는 **파일을 만든 사람만** 가능하도록 제한하는 권한이다.

## 2. 프로세스 관리 (Process Management)
프로세스는 실행 중인 프로그램을 의미하며, 리눅스 시스템 운영의 핵심 단위다.

### 1) 프로세스의 계층 구조
모든 프로세스는 부모-자식 관계를 가진다. 
* **systemd**: 모든 시스템 프로세스의 최상위 부모이며 PID(프로세스 식별 번호) 1번을 가진다.
* **프로세스 상태**:
    - **고아 프로세스**: 자식보다 부모가 먼저 종료된 경우로, 1번 프로세스가 대신 부모 역할을 맡아 정리한다.
    - **좀비 프로세스**: 작업이 끝났음에도 프로세스 테이블에 남아 자원을 차지하는 상태다. 부모에게 신호를 보내 정리해야 한다.

### 2) 프로세스 제어 명령어
* **ps**: 현재 실행 중인 프로세스 목록을 확인한다. `ps -ef`나 `ps aux` 명령을 주로 사용한다.
* **top**: 실시간으로 CPU 및 메모리 사용량을 모니터링한다.
* **kill**: 특정 프로세스에 시그널을 보내 종료시킨다. `kill -9 [PID]`는 강제 종료를 의미한다.

## 3. 작업 제어 및 예약
터미널 하나에서 여러 작업을 동시에 관리하거나 정해진 시간에 명령을 실행할 수 있다.

### 1) 포그라운드와 백그라운드
* **포그라운드**: 명령 실행 후 끝날 때까지 기다려야 하는 기본 방식이다.
* **백그라운드**: 명령 끝에 `&`를 붙여 실행하며, 프롬프트가 바로 돌아와 다른 작업을 동시에 할 수 있다. 수행 시간이 긴 작업에 유용하다.
* **전환**: `Ctrl + z`로 작업을 중단하고 `bg` 명령으로 백그라운드로 보낼 수 있다.


### 2) 작업 예약 시스템
* **at**: **정해진 시간에 딱 한 번** 실행할 작업을 예약한다.
* **crontab**: **주기적으로 반복**되는 작업을 예약한다.
    - 설정 형식: `분 시 일 월 요일 명령` (예: `30 23 1 * *`은 매월 1일 23시 30분 실행)
    - 사용 제한: `/etc/cron.allow` 및 `cron.deny` 파일을 통해 특정 사용자의 예약 권한을 관리할 수 있다.
