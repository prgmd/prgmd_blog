## 1. 리눅스(Linux) 시스템 개요

Linux는 리누스 토발즈가 UNIX를 참조하여 개발한 오픈 소스 운영체제. 윈도우와 달리 소스코드가 공개되어 있고, 이를 토대로 전 세계 개발자들이 기능을 마구마구 추가하며 Ubuntu, CentOS, Debian, Red Hat 등의 다양한 배포판을 발전시킴. 여러 사용자가 동시 접속해 각기 다른 작업을 수행할 수 있는 환경을 제공하기도 했다.

### 1.1 리눅스의 내부 구조

\> 계층 구조를 가지고 있고, 각 층끼리 상호작용을 통해 하드웨어를 구동하고 사용자 명령을 수행함.

* **커널(Kernel)**: **하드웨어 자원을 직접 제어하고 관리**하는 가장 핵심적인 부분. 프로세스 관리, 메모리 할당, 파일 시스템 관리, 디바이스 드라이버 제어 등을 담당하며 사용자 앱이 하드웨어에 직접 접근하지 못하게 보호한다.
* **셸(Shell)**: 사용자가 입력한 명령을 해석해 커널에 전달하는 번역기, 중계자 역할. 사용자가 입력한 텍스트를 커널이 이해할 수 있도록 이진 신호로 변환한다. 종류가 여러 개인데, 가장 널리 쓰이는 건 **bash**(Bourne Again Shell). 
* **애플리케이션(Application)**: 사용자에게 특정 기능을 제공하는 프로그램 층. 웹 브라우저, 텍스트 에디터, 컴파일러, 데이터베이스가 여기에 해당한다. 애플리케이션이 하드웨어 자원을 사용해야할 때는 **시스템 호출 통로를 통해 커널에 요청을 보낸다.**

### 1.2 가상화와 접속 환경

사실 Linux의 경우 물리 서버로 다룬다기 보다 대부분 가상화 환경에서 돌리는 일이 부지기수.

* **가상화**: 하나의 컴퓨터에서 여러 OS를 동시에 돌리는 기술이다. Virtual Box, VMware, KVM 등 사용.
* **NAT**: VM이 외부 인터넷과 통신하기 위해 내부 사설 IP 주소를 외부 공인 IP 주소로 변환하는 기술. VM은 대개 호스트 컴퓨터의 IP를 빌려 인터넷에 접속한다.
* **SSH**: 원격 서버에 안전하게 접속하기 위한 보안 프로토콜. 모든 데이터가 암호화되어 전송된다. 리눅스 서버 관리에 필수.

### 1.3 셸(Shell)

#### 셸의 종류와 특징

* **Bash Shell (배시 셸)**: 리눅스의 표준 셸이자 우분투의 기본 셸. 본 셸(Bourne)과 호환되면서 다양한 기능을 포함하고 있음.
* **Dash Shell**: 가벼운 본 셸 기반의 셸로, 우분투에서 시스템 스크립트 실행용으로 널리 쓰임.
* **사용자 셸 변경**: `chsh -s [셸경로]` 명령을 사용하여 로그인 셸을 원하는 것으로 변경할 수 있다.

## 2. 터미널 프롬프트

리눅스는 CLI 환경에서 텍스트 기반의 명령어를 통해 시스템을 제어한다.

### 2.1 **프롬프트 구성**

```
사용자명@호스트명:현재디렉토리$
```

예를 들어 `ubuntu@linux-server:~$`인 경우, `ubuntu`라는 계정으로 `linux-server`라는 컴퓨터에 접속해 현재 `~` 경로에 있는 것.

* `~`: 사용자의 홈 디렉토리 약어
* 끝 기호가 `$`이면 일반 사용자, `#`이면 모든 권한을 가진 슈퍼 사용자(Root)를 의미.
* **명령어 구조**: `명령어 [옵션] [인자]` 순서로 입력하며 공백으로 구분. 옵션은 보통 `-`(한 글자)나 `--`(단어)로 시작한다.

### 2.2 유용한 기본 명령어

* **ls**: List Segments. 현재 디렉토리의 파일 목록을 보여준다.

  * `ls -l` : 상세 표시(파일 권한, 소유자, 크기, 수정 날짜...)
  * `ls -a`: 숨겨진 파일까지 모두 표시 
* **history**: 이전에 입력했던 명령어 목록을 확인한다.

  * `!!`: 바로 직전 명령을 다시 실행.
  * `!번호`: 히스토리 목록 중 해당 번호 명령어 실행.
* **sudo**: SuperUser Do. 관리자 권한을 잠시 빌려 명령을 수행한다.
* **man**: 특정 명령어의 사용법(매뉴얼)을 상세히 보여준다. (종료시 `q`)
* **clear**: 터미널 내 텍스트 지우기.

### 2.3 입출력 리다이렉션

> 장치도 파일로 관리함!

* **표준 스트림 번호**: 0(입력), 1(출력), 2(에러)
* **출력 리다이렉션**: `>`는 기존 내용을 덮어쓰고, `>>`는 기존 내용 끝에 추가한다.
* **에러 리다이렉션**: `2>`를 사용하여 에러 메시지만 따로 파일에 기록할 수 있다. `2>&1`을 쓰면 정상 출력과 에러를 한 파일에 섞어서 저장한다.

## 3. Vim 편집기 마스터하기

Vim은 리눅스에서 가장 널리 쓰이는 화면 단위 편집기. 마우스 없이 키보드 모드 전환만으로 모든 편집을 수행한다.

### 3.1 3가지 주요 모드

* **명령 모드 (Command Mode)**: 처음 파일을 열었을 때의 상태다. 커서 이동, 삭제, 복사가 가능하다.
* **입력 모드 (Insert Mode)**: `i`나 `a`를 눌러 진입하며, 실제로 글자를 타이핑하는 모드다. `ESC`를 누르면 다시 명령 모드로 돌아온다.
* **마지막 행 모드 (Last-line Mode)**: `:`를 눌러 진입하며, 파일 저장(`:w`)이나 종료(`:q`)를 수행한다.

### 3.2 필수 단축키

| 분류          | 단축키        | 기능 설명                        |
| ----------- | ---------- | ---------------------------- |
| **커서 이동**   | `Ctrl + A` | 커서를 줄의 맨 앞으로 이동              |
|             | `Ctrl + E` | 커서를 줄의 맨 뒤로 이동               |
|             | `Alt + B`  | 커서를 한 단어 뒤(왼쪽)로 이동           |
|             | `Alt + F`  | 커서를 한 단어 앞(오른쪽)로 이동          |
| **텍스트 편집**  | `Ctrl + U` | 커서 위치부터 줄의 처음까지 삭제           |
|             | `Ctrl + K` | 커서 위치부터 줄의 끝까지 삭제            |
|             | `Ctrl + W` | 커서 바로 앞의 단어 하나 삭제            |
|             | `Ctrl + Y` | 삭제(잘라내기)한 내용을 붙여넣기           |
| **프로세스 제어** | `Ctrl + C` | 실행 중인 명령어를 즉시 강제 종료          |
|             | `Ctrl + Z` | 실행 중인 명령어를 일시 중지 (배경으로 보냄)   |
|             | `Ctrl + D` | 터미널 종료 (exit 명령어와 동일)        |
| **기타 편의**   | `Tab`      | 파일명, 디렉토리명 자동 완성 (**가장 중요**) |
|             | `Ctrl + L` | 터미널 화면 깨끗이 지우기 (clear와 동일)   |
|             | `Ctrl + R` | 이전에 사용했던 명령어 히스토리 검색         |

#### 이동 및 검색 (명령 모드)

| 단축키          | 기능 설명                               |
| ------------ | ----------------------------------- |
| `h, j, k, l` | 왼쪽, 아래, 위, 오른쪽 이동                   |
| `w` / `b`    | 다음 단어 앞부분으로 이동 / 이전 단어 앞부분으로 이동     |
| `0` / `$`    | 현재 줄의 맨 처음으로 이동 / 맨 끝으로 이동          |
| `gg` / `G`   | 파일의 첫 번째 줄로 이동 / 마지막 줄로 이동          |
| `:[번호]`      | 해당 행 번호로 즉시 이동                      |
| `/단어`        | 아래 방향으로 단어 검색 (`n`은 다음, `N`은 이전 결과) |

#### 편집 및 복사 (명령 모드)

| 단축키              | 기능 설명                                |
| ---------------- | ------------------------------------ |
| `i` / `a` / `o`  | 현재 칸에서 입력 / 다음 칸에서 입력 / 아래 줄 추가 후 입력 |
| `x`              | 커서가 있는 글자 삭제                         |
| `dw`             | 커서 위치의 단어 삭제                         |
| `dd`             | 현재 줄 전체 삭제 (잘라내기)                    |
| `yy`             | 현재 줄 복사                              |
| `p` / `P`        | 현재 줄 아래에 붙여넣기 / 현재 줄 위에 붙여넣기         |
| `u` / `Ctrl + R` | 작업 취소(Undo) / 취소한 작업 되돌리기(Redo)      |

#### 저장 및 종료 (마지막 행 모드)

| 명령어          | 기능 설명            |
| ------------ | ---------------- |
| `:w`         | 변경 사항 저장         |
| `:q`         | 종료 (변경 사항이 없을 때) |
| `:wq` / `:x` | 저장 후 종료          |
| `:q!`        | 저장하지 않고 강제 종료    |
| `:set nu`    | 줄 번호 표시          |

### 3.3 버퍼(Buffer) 이해하기

Vim에서 '삭제'나 '복사'를 하면 해당 내용은 메모리의 특정 공간인 버퍼(레지스터)에 담긴다.

* **언네임드 버퍼 (Unnamed Buffer)**: 기본적으로 사용하는 공간입니다. `dd`나 `yy`를 하면 자동으로 이곳에 저장되며, 가장 최근에 처리한 내용 1개만 기억한다.
* **네임드 버퍼 (Named Buffer)**: 알파벳(a-z)을 사용하여 여러 내용을 따로 보관할 수 있다.

  * **저장**: `"ayy` (a라는 이름의 버퍼에 현재 줄 복사)
  * **사용**: `"ap` (a 버퍼에 들어있는 내용 붙여넣기)
* 여러 파일을 동시에 열 때, 각 파일은 고유의 버퍼 번호를 할당받음. `:ls` 명령어로 현재 열려 있는 버퍼 목록을 확인하고 `:b [번호]`를 통해 파일 사이를 빠르게 전환하자.

### 3.4 파일 관리 및 시스템 명령 처리

Vim을 종료하지 않고도 외부 파일을 불러오거나 셸(Shell)과 상호작용할 수 있음.

* **파일 읽기 및 전환** (`:r`, `:e`)

  * `:r [파일명]`: 외부 파일의 내용을 복사해 현재 커서 위치에 붙여넣음. (Read)
  * `:e [파일명]`: 현재 파일을 닫고(저장 필요) 지정한 파일을 새로 염. (Edit)
* **셸 명령 실행** (`:!`, `:sh`)

  * `:![명령어]`: 편집을 중단하지 않고 잠시 밖으로 나가 명령 결과를 확인. (예: :!ls로 파일 목록 확인 후 Enter를 눌러 복귀)
  * `:sh`: 현재 Vim 세션을 배경에 두고 셸로 완전히 빠져나감. 작업을 마친 후 exit를 입력하면 다시 Vim으로 돌아온다.
* **편집 가속화 기능**

  * `.` (점): 가장 최근에 수행한 편집 명령(삭제, 삽입 등)을 그대로 반복합니다. 반복적인 수정 작업 시 매우 유용하다.
  * `~` (틸트): 커서 위치의 영문자를 대문자는 소문자로, 소문자는 대문자로 즉시 전환한다.

### 3.5 환경 설정 최적화

매번 환경 설정 명령을 입력하는 번거로움을 줄이기 위해 설정 파일을 활용.

#### `.exrc` (또는 `.vimrc`) 파일 활용

리눅스 시스템은 Vim이 시작될 때 사용자의 홈 디렉토리(`~`)에 있는 `.exrc` (전통적 vi) 또는 `.vimrc` (현대적 vim) 파일을 읽어 설정을 자동 적용.

#### 주요 설정 명령어 요약

| 명령                        | 기능 설명                                             |
| ------------------------- | ------------------------------------------------- |
| **`set nu`** (number)     | 각 행의 왼쪽에 줄 번호를 표시합니다.                             |
| **`set nonu`**            | 줄 번호 표시를 해제합니다.                                   |
| **`set list`**            | 탭(`^I`), 줄 바꿈(`$`) 등 눈에 보이지 않는 **제어 문자**를 시각화합니다. |
| **`set nolist`**          | 제어 문자 시각화를 해제합니다.                                 |
| **`set showmode`**        | 현재 하단에 'INSERT' 등 어떤 모드인지 상태를 표시합니다.              |
| **`set ic`** (ignorecase) | 검색 시 대소문자를 구분하지 않습니다.                             |
| **`set ai`** (autoindent) | 윗줄의 들여쓰기에 맞춰 다음 줄 들여쓰기를 자동 적용합니다.                 |
| **`set all`**             | 현재 설정된 모든 옵션의 상태 값을 화면에 출력합니다.                    |
