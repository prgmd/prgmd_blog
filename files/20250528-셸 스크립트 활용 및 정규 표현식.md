## 1. 셸 스크립트 연산자 (Operators)
스크립트 내에서 조건문을 작성할 때 사용하는 연산자들은 대상의 종류(문자열, 숫자, 파일 등)에 따라 구분된다.

### 1) 문자열 및 정수 비교
* **문자열 연산자**: 
    - `-z`: 문자열의 길이가 0이면 참이다.
    - `-n`: 문자열의 길이가 0이 아니면 참이다.
* **정수 비교 연산자**: `-eq`(같음), `-ne`(다름), `-gt`(큼), `-ge`(크거나 같음), `-lt`(작음), `-le`(작거나 같음) 등이 있다. 기호(`<`, `>`)를 직접 사용하여 비교할 때는 `[[ ]]` 구문을 사용해야 한다.

### 2) 파일 및 디렉토리 연산자
파일의 상태나 권한을 확인하여 로직을 구성할 때 유용하다.
* **유형 확인**: `-d`(디렉토리), `-f`(일반 파일), `-L`(심볼릭 링크).
* **권한 및 속성**: `-r`(읽기), `-w`(쓰기), `-x`(실행), `-s`(크기가 0보다 큼).
* **비교 연산**: `-nt`(최신 파일 여부), `-ot`(이전 파일 여부), `-ef`(동일 파일 여부).

## 2. 정규 표현식 (Regular Expression)
특정 문자열 패턴을 탐색하거나 조작할 때 사용하는 문자 집합이다. `grep` 명령어와 결합하여 강력한 텍스트 필터링 기능을 제공한다.

### 1) 주요 문법 요소
* **패턴 매칭**: `.`(한 문자), `*`(0번 이상 반복), `+`(1번 이상 반복), `?`(0회 또는 1회 발생).
* **위치 지정**: `^`(라인 시작), `$`(라인 끝), `^$`(빈 줄).
* **문자 클래스**: `[:alnum:]`(알파벳과 숫자), `[:alpha:]`(알파벳), `[:digit:]`(숫자) 등을 대괄호`[[ ]]` 안에 넣어 사용한다.



### 2) 실무 활용 예시 (grep)
* **특정 단어 검색**: `grep 'C.U' [파일명]` (C로 시작하고 U로 끝나는 세 글자 탐색).
* **빈 줄 및 주석 제거**: `cat [파일명] | grep -v '^#' | grep -v '^$'` (#으로 시작하거나 내용이 없는 줄 제외).
* **정확한 단어 일치**: `-w` 옵션을 사용하여 패턴과 완전히 일치하는 단어만 추출한다.

## 3. 텍스트 처리 도구 (awk & find)
* **awk**: 표 형식의 데이터에서 특정 컬럼만 추출할 때 유용하다. `$1`, `$2` 등으로 필드를 지정한다.
* **find**: 파일명, 경로 등을 기준으로 시스템 내 파일을 검색한다.

## 4. 실습: 사용자 계정 자동 생성 스크립트
여러 사용자의 아이디와 비밀번호를 매개변수로 받아 일괄 생성하는 스크립트 예시다.

```bash
#!/bin/bash
# adduser-script.sh "user01 user02" "pw01 pw02"

if [[ -n $1 ]] && [[ -n $2 ]] # 매개변수 존재 확인
then
    UserList=($1)
    Password=($2)
    for (( i=0; i<${#UserList[@]}; i++ )) # 배열 순회
    do
        # 기존 계정 존재 여부 확인
        if [[ $(cat /etc/passwd | grep ${UserList[$i]} | wc -l) == 0 ]]
        then
            sudo useradd ${UserList[$i]} # 계정 생성
            echo ${Password[$i]} | sudo passwd ${UserList[$i]} # 비밀번호 설정
        else
            echo "this user ${UserList[$i]} is existing" # 중복 메시지
        fi
    done
else
    echo -e 'Usage: adduser-script.sh "user01 user02" "pw01 pw02"' # 도움말
fi
```
