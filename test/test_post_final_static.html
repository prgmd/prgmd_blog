Chapter I. numpy 사용법

1. ndarray의 기본 구조 파악하기

NumPy 배열(ndarray)은 파이썬의 리스트와 비슷해 보이지만, 훨씬 강력한 기능을 가짐. AI 학습을 위해서는 선형대수학 개념이 나름 필수적인데, 그렇기 때문에 선형대수학을 지원하고 빠른 속도를 제공하는 NumPy 사용은 사실상 불가결. (물론 그 외에도 확통, 미적분, 이산수학 등이 필요하다)

1-1. 주요 함수

속성 의미
np.array 리스트 등을 활용한 넘파이 배열 생성
ndim 배열의 차원 수 (1차원, 2차원 등)
shape 배열의 형태 (행, 열의 개수)
size 배열 내 전체 요소의 개수
dtype 요소의 데이터 타입 (int, float 등) 
import numpy as np

arr = np.array([[1, 2], [3, 4]])

print(arr)           # 배열 출력
print(arr.ndim)      # 차원: 2
print(arr.shape)     # 모양: (2, 2)
print(arr.size)      # 개수: 4
print(arr.dtype)     # 타입: int64

1-2. 연산자

구분 연산자 / 메서드 핵심 동작 주요 특징
요소별 곱 * (Asterisk) 동일 위치 원소끼리 곱 두 배열의 Shape이 동일해야 함 (또는 브로드캐스팅 가능)
행렬 곱 @ (At symbol) 표준 행렬 곱셈 (Dot product) Python 3.5+ 표준. 앞 열 = 뒤 행 크기가 맞아야 함
내적/행렬 곱 .dot() 행렬 곱 및 벡터 내적 @와 거의 동일하나, 스칼라 곱 시 결과가 다를 수 있음 
A = np.array([1, 2])
B = np.array([3, 4])
# 결과: [1*3, 2*4] -> [3, 8]

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
# 결과: [[(1*5+2*7), (1*6+2*8)], [(3*5+4*7), (3*6+4*8)]] -> [[19, 22], [43, 50]]

2. 선형대수

2-1. 행렬 표현

2차원 좌표계는 (3, 4)를 [3, 4]로 표현. 거리는 유클리드 거리를 통해 구한다.

유클리드 거리 (L2 Norm)

$$||x||_2 = \sqrt{a^2 + b^2}$$ 두 지점 사이의 최단 거리를 구하는 방식 (피타고라스 정리 기반)

2-1. 선형 변환

항목 설명
스칼라 배 (*) 배열의 모든 원소에 특정 숫자를 곱하는 연산
단위 행렬 (I) 곱셈 연산 시 자기 자신을 그대로 유지하는 행렬 (항등원)
선형 변환 (@) 행렬을 이용해 벡터의 위치나 형태를 변형시키는 연산
90도 회전 행렬 좌표를 특정 각도(시계 방향 90도)로 회전시키는 특수 행렬 
import numpy as np

# 1. 스칼라 배
print(3 * np.array([1, 2]))           # [3 6]

# 2. 단위 행렬 및 선형 변환 (@)
v = np.array([1, 2])
I = np.eye(2)                         # 단위 행렬 [[1, 0], [0, 1]]
print(I @ v)                          # [1. 2.] (변화 없음)

# 3. 90도 회전 변환 (시계 방향)
R = np.array([[0, 1], [-1, 0]])
print(R @ v)                          # [2 -1]

2-2. 배열 생성과 랜덤 함수

함수 설명
zeros 모든 원소의 값이 0인 지정된 모양의 배열을 생성함
random.seed 난수 생성기의 시드 값을 고정하여 실행 시마다 동일한 결과를 얻게 함
random.rand 0 이상 1 미만의 범위에서 지정된 개수만큼 무작위 실수를 생성함 
import numpy as np

# 1. 모든 값이 0인 2행 3열 배열
print(np.zeros((2, 3)))

# 2. 결과 고정을 위한 시드 설정
np.random.seed(42)

# 3. 0~1 사이 무작위 실수 3개 생성
print(np.random.rand(3))

2-3. 수학 및 지수/로그 함수

함수 의미 특징
log2 밑이 2인 로그 컴퓨터 과학의 비트 계산이나 정보량(엔트로피) 계산 시 주로 사용됨
log 자연 로그 ($\ln$) Numpy에서 기본 log는 밑이 $e$인 자연 로그를 의미함
exp 지수 함수 ($e^x$) 자연상수 $e$의 거듭제곱을 계산하며, 딥러닝 활성화 함수 등에서 필수적임 
import numpy as np

# 1. 밑이 2인 로그 (8은 2의 3제곱)
print(np.log2(8))     # 3.0

# 2. 자연 로그 (e의 값은 약 2.718)
print(np.log(np.e))   # 1.0

# 3. 지수 함수 (e의 1제곱)
print(np.exp(1))      # 2.718281828459045

2-4. 행렬 조작

기능 설명
triu Upper Triangle. 행렬에서 대각선 위쪽 성분만 남기고 나머지는 0으로 채움 (상관계수 행렬 시각화 시 유용)
T Transpose. 행렬의 행과 열을 맞바꾸는 전치 연산을 수행함
linspace Linear Space. 시작값부터 끝값까지 지정된 개수만큼 동일한 간격으로 숫자를 생성함 (그래프 x축 생성용) 
import numpy as np

arr = np.array([[1, 2], [3, 4]])

# 1. 상삼각 행렬 (Upper Triangle)
print(np.triu(arr))      # [[1, 2], [0, 4]]

# 2. 전치 행렬 (Transpose)
print(arr.T)             # [[1, 3], [2, 4]]

# 3. 선형 간격 데이터 생성 (0~10 사이 5개)
print(np.linspace(0, 10, 5))  # [ 0.   2.5  5.   7.5 10. ]

2-3. 데이터 시각화 라이브러리

  • Matplotlib: 파이썬 시각화의 조상님. 세밀하게 설정 가능하지만 코드가 좀 긴 편.
  • Seaborn: Matplotlib을 기반으로 만든 고급 라이브러리. 특히 Pandas 데이터프레임과 궁합이 좋다. 디자인이 조금 더 낫고, 통계 차트(히트맵, 분포도 등)를 그리기에 매우 편리하다고.
    • 기본적으로 AI에서는 Matplot을 많이 사용하지만, Pandas를 사용할 경우 Seaborn을 많이 사용하는 편.
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

# 1. linspace로 x축 만들기 (0~2π 구간을 100개로 쪼개기)
x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)

# 2. Matplotlib으로 기본 그래프 그리기
plt.plot(x, y)
plt.show()

# 3. Seaborn과 Pandas 활용
data = pd.DataFrame({'x': x, 'y': y})
sns.lineplot(data=data, x='x', y='y')
plt.show()

3. Pandas

파이썬에서 데이터를 쉽고 효율적으로 다룰 수 있도록 돕는 데이터 분석용 라이브러리. 엑셀처럼 행과 열로 이루어진 표 형태의 데이터를 처리하는 데 최적화되어 있다. 가장 큰 특징으로는 데이터를 DataFrame이라는 구조로 관리한다는 점.

3-1. 핵심 구조와 특징

구조

  • 시리즈: 데이터의 한 열
  • 레코드: 데이터의 한 행
  • DataFrame : 엑셀 시트 전체(2차원 표 형태, 여러 시리즈의 조합)

특징

  • CSV, Excel, SQL, JSON 등 거의 모든 형태의 데이터를 바로 불러올 수 있음.
  • 지저분한 데이터(결측치 nan, 중복 데이터)를 지우거나, 특정 조건에 맞는 데이터만 뽑아내는 데이터 전처리 작업이 매우 빠르다. (dropna, where)
  • 파이썬 기본 리스트나 딕셔너리보다 훨씬 많은 양의 데이터를 메모리 효율적으로 계산 가능.
  • 데이터의 통계치(평균, 합계 등)를 구한 뒤 바로 그래프로 시각화하기가 쉽다.
import pandas as pd

# 데이터 만들기 (딕셔너리 형태)
data = {
    '이름': ['김철수', '이영희', '박민수'],
    '점수': [85, 92, 78],
    '합격여부': [True, True, False]
}

# DataFrame으로 변환
df = pd.DataFrame(data)

# '점수'가 80점 이상인 사람만 필터링
high_score = df[df['점수'] >= 80]

print(high_score)

3-2. 데이터 확인 (Quick Look)

함수 용도 비고
df.head(n) 상위 $n$개 데이터 확인 기본값 5, 데이터 생김새 파악용
df.info() 데이터 명세 확인 컬럼명, Non-Null 개수, 데이터 타입 확인
df.describe() 요약 통계량 확인 평균, 표준편차, 4분위수 등 수치 데이터 분석
df.shape 데이터 크기 확인 (행, 열) 형태의 튜플 반환
df.columns 컬럼명 목록 확인 전체 열 이름을 리스트 형태로 반환

3-3. 데이터 선택 (Selection)

  • 컬럼 선택
    • df['a']: 시리즈(Series) 형태로 한 개의 열 추출
    • df[['a', 'b']]: 데이터프레임(DataFrame) 형태로 여러 열 추출
  • 인덱서 (Loc vs Iloc)
    • df.loc[]: 이름(Label) 기반 선택. df.loc[0, 'a']
    • df.iloc[]: 위치(Index) 기반 선택. df.iloc[0, 1]

주의: 여러 조건을 조합할 때는 반드시 각 조건을 소괄호 ()로 감싸야 하며, and/or 대신 & (AND), | (OR) 연산자를 사용.

# 1. 단일 조건: 팁이 5달러 이상
df[df['tip'] >= 5]

# 2. 다중 조건: 팁 5달러 이상이면서 남성인 경우
df[(df['tip'] >= 5) & (df['sex'] == 'Male')]

3-4. 기초 집계 (Aggregation)

  • 주요 함수: mean()(평균), sum()(합계), count()(개수), std()(표준편차), min()/max()
  • 활용 예시:
    • df['tip'].mean() : 전체 팁 평균값
    • df[['tip', 'total_bill']].sum() : 여러 컬럼의 합계를 한 번에 계산

3-5. 심화 함수

Groupby

데이터를 특정 기준에 따라 쪼개고(Split), 함수를 적용한 뒤(Apply), 다시 합치는(Combine) 과정.

  • 핵심 패턴: df.groupby('기준')['대상'].함수()
  • 다중 그룹화: df.groupby(['A', 'B']) 처럼 리스트를 전달하면 계층적 분석이 가능합니다.
  • Tip: 결과를 다시 데이터프레임으로 만들고 싶다면 끝에 .reset_index()를 붙여주는 것이 좋습니다.

Pivot

중복된 데이터를 요약하여 교차표(Cross-tab) 형태로 만듦. 엑셀의 피벗 테이블과 동일한 기능이다.

  • Index: 행으로 갈 컬럼
  • Columns: 열로 펼쳐질 컬럼
  • Values: 채워질 값

Melt (Long-format 변환)

옆으로 넓게 퍼진(Wide) 데이터를 아래로 길게(Long) 늘어뜨린다. Seaborn이나 Plotly 같은 시각화 라이브러리를 쓸 때 가장 많이 사용되는 형태.

  • id_vars: 변하지 않고 고정될 컬럼
  • value_vars: 행으로 녹여낼 컬럼들
  • var_name / value_name: 새로 생성될 컬럼들의 이름 지정
